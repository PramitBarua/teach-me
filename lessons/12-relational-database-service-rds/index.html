RDS & Aurora

Relational Database Service (RDS) & Aurora

16 lessons · ~2 hours total

Source: Adrian Cantrill SAA-C03 · AWS RDS User Guide · AWS Aurora User Guide

This module covers AWS's managed relational database services — from the fundamentals of relational and NoSQL data models through to RDS, Amazon Aurora, and database migration. Databases are one of the most heavily-tested domains on the SAA-C03 exam, and the concepts here (Multi-AZ vs read replicas, RDS vs Aurora architecture, backup/restore mechanics) recur constantly in scenario questions.

# Lesson Key idea
01 Relational Database Fundamentals Tables, attributes, primary keys, composite keys, fixed schema defined in advance
02 NoSQL Database Models Key-value, wide column, document, column (OLAP), graph — and their AWS products
03 ACID vs BASE CAP theorem trade-off; ACID → RDS, BASE → NoSQL, by default
04 Databases on EC2 Always possible, usually a bad idea; weigh OS-access needs against admin overhead
05 RDS Architecture DB subnet groups, dedicated EBS storage per instance, resource-based billing
06 RDS Multi-AZ: Instance vs Cluster Instance mode = 1 unusable standby; cluster mode = 2 usable readers, faster failover
07 RDS Backups, Snapshots & Restore Manual snapshots never expire; automated backups + transaction logs enable point-in-time restore
08 RDS Read Replicas Asynchronous, usable for reads, near-zero RTO for failure — not for corruption
09 RDS Data Security KMS/EBS vs TDE encryption at rest; IAM auth is authentication only, not authorization
10 RDS Custom Middle ground between RDS and EC2; Oracle and SQL Server only; niche but exam-visible
11 Amazon Aurora Architecture Shared cluster storage, usable replicas, Backtrack, fast clone
12 Aurora Serverless ACUs from a warm pool, proxy fleet, scale-to-zero for variable/unpredictable workloads
13 Aurora Global Database Sub-second, one-way, storage-layer replication across Regions for DR and global reads
14 Aurora Multi-Master Writes Every instance writable; quorum-based commits; foundation for app-level fault tolerance
15 RDS Proxy Connection pooling + multiplexing; abstracts failover away from the application
16 Database Migration Service (DMS) Replication instances/tasks, full load vs CDC, SCT only when the engine changes
Exam scope
The highest-yield topics in this module are the synchronous vs asynchronous distinction (Multi-AZ vs read replicas), the architectural differences between standard RDS and Aurora (dedicated storage vs shared cluster storage), and knowing when DMS and SCT are each required for a migration scenario.
