CloudTrail

Lesson 10 of 11 · ~8 min

Source: Adrian Cantrill SAA-C03 · CloudTrail Docs

What is CloudTrail?

AWS CloudTrail records every API call and account activity across your AWS account. Every action taken — via the console, CLI, SDK, or another AWS service — is logged as a CloudTrail event.

Default Behaviour

  • CloudTrail is enabled by default for all AWS accounts.
  • 90 days of event history are stored at no cost, visible in the CloudTrail console.
  • To keep logs longer or process them programmatically, deliver them to an S3 bucket (where they can stay indefinitely for the cost of S3 storage alone).

Trail Types

TypeWhat it logs
One-region trail Only records events from the region in which it is created.
All-regions trail Records events from every region, including global services (IAM, STS, CloudFront). Recommended default.

Event Types

Event typeExamplesDefault?Cost
Management events Create/delete resources, attach policies, configure services (control-plane) Yes Free for first copy per region
Data events S3 object reads/writes, Lambda invocations (data-plane) No Extra cost
CloudTrail is NOT real-time
Events typically appear in the trail within 15 minutes of the account activity. Do not rely on CloudTrail for immediate alerting — use CloudWatch Events / EventBridge for that.
Exam tip
Who did what, when? → CloudTrail.
What is happening in my application right now? → CloudWatch.
These are the two most commonly confused services in exam questions.
