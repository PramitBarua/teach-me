IAM Identity Policies

Lesson 01 of 11 · ~10 min

What is an IAM Identity Policy?

An IAM Identity Policy is a JSON document attached to an AWS identity (user, group, or role). It tells AWS which actions that identity is allowed or denied on which resources.

AWS identities are:

  • IAM User – a single person or application
  • IAM Group – a collection of users
  • IAM Role – a short-term identity assumed by a service or person

Anatomy of a Policy Statement

Every policy is a list of statements. Each statement has four key fields:

FieldRequired?What it does
SidOptionalA human-readable label for the statement
EffectYesAllow or Deny
ActionYesWhich API operations, e.g. s3:GetObject or s3:*
ResourceYesWhich AWS resources the statement applies to, specified as ARNs

A statement only applies when the action and resource of the incoming request match the statement.

The Three Outcomes: Allow, Deny, or Implicit Deny

When AWS evaluates an identity's access to a resource it runs through all attached policies and arrives at one of three outcomes:

Explicit Deny
A statement with "Effect": "Deny" matches. Deny always wins — it overrides any allow.
Explicit Allow
No deny matched, but a statement with "Effect": "Allow" did. Access is granted.
Implicit Deny
No statement matched at all. Everything in AWS is denied by default.
Exam tip
The evaluation order is: Explicit Deny → Explicit Allow → Implicit Deny. If you see a question where a deny policy and an allow policy overlap, the deny wins.

Managed Policies vs Inline Policies

TypeStored asReusable?When to use
AWS Managed Standalone JSON doc (AWS-owned) Yes – attach to any identity Common permission sets (e.g. ReadOnlyAccess)
Customer Managed Standalone JSON doc (you own) Yes – attach to any identity Custom permissions you manage
Inline Embedded inside one identity No – one identity only Exceptional or one-off allows/denies only
Rule of thumb
Prefer managed policies — they reduce admin overhead because one change updates every identity that uses the policy. Reserve inline policies for truly exceptional cases.
