CloudWatch Logs

Lesson 09 of 11 · ~8 min

Source: Adrian Cantrill SAA-C03 · CloudWatch Logs Docs

What is CloudWatch Logs?

Amazon CloudWatch Logs is a public AWS service that stores, monitors, and provides access to log data. It is a regional service — log data stays in the region it was ingested in.

Sources can be AWS services (Lambda, VPC Flow Logs, Route 53, etc.) or on-premises systems via the unified CloudWatch agent.

The Hierarchy

ConceptDescription
Log Event The smallest unit. A timestamp + a message (any blob of text — structured or unstructured).
Log Stream An ordered sequence of log events from one source (e.g. one EC2 instance, one Lambda execution environment).
Log Group A container for multiple log streams from the same type of source (e.g. /aws/lambda/my-function). Retention policies and permissions are set at the log group level.

Metric Filters and Alarms

A metric filter can scan log data in a log group and produce a numeric metric when a pattern matches (e.g. count of "ERROR" log lines). You can then create a CloudWatch Alarm on that metric to trigger notifications or auto-scaling.

Exam tip
Retention and permissions are configured per log group, not per stream. If you want different retention for different services, put them in separate log groups.
