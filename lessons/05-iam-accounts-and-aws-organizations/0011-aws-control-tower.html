AWS Control Tower

Lesson 11 of 11 · ~8 min

Source: Adrian Cantrill SAA-C03 · AWS Control Tower Docs

What is AWS Control Tower?

AWS Control Tower automates the setup and ongoing governance of a secure, compliant, multi-account AWS environment. It sits on top of AWS Organizations and adds a layer of automated policy enforcement and account provisioning.

Relationship to AWS Organizations
Control Tower uses Organizations under the hood. If you already have an org, Control Tower can be enabled on top of it. Think of Organizations as the plumbing; Control Tower as the governance layer built on that plumbing.

Core Concepts

Landing Zone
The multi-account environment that Control Tower sets up for you — a pre-configured hierarchy of OUs, accounts, and baselines (logging, security tooling, identity). It is the "starting point" for a well-governed AWS estate.
Guardrails (Controls)
Pre-built policies that enforce governance. There are two kinds:
  • Preventive guardrails — implemented as SCPs; prevent non-compliant actions from being taken at all.
  • Detective guardrails — implemented as AWS Config rules; identify resources that are already non-compliant and report them.
Account Factory
A self-service mechanism for provisioning new AWS accounts that automatically comply with the landing zone standards. Each new account is vended with guardrails, logging, and identity access pre-configured. Eliminates manual account setup toil.
Exam tip
For the SAA-C03 exam, know the high-level purpose of each concept:
Landing zone = the governed environment.
Guardrails = ongoing policy enforcement (preventive → SCP; detective → Config).
Account Factory = automated, standardised new-account provisioning.

Retrieval Practice

1. Which Control Tower feature automatically provisions new AWS accounts with governance baselines pre-applied?

2. A preventive guardrail in Control Tower is implemented using which underlying AWS mechanism?

3. A detective guardrail finds that an S3 bucket in a member account has public access enabled, which violates company policy. What does the guardrail do?
