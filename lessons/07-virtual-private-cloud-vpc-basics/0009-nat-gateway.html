NAT & NAT Gateway

Lesson 09 of 09 · ~11 min

Source: Adrian Cantrill SAA-C03 · AWS NAT Gateway Docs

What NAT Does and Why

Network Address Translation (NAT) lets private instances initiate outbound connections to the internet or AWS public services (S3, SQS, etc.) without being reachable from the internet. It is a many-to-one mapping: many private IP addresses share a single public IP.

Compare this to an Internet Gateway, which does a one-to-one static NAT between a private and a public IP. NAT is for private instances that need outbound-only internet access and should never be directly reachable.

Internet Gateway (IGW)NAT Gateway
IP mappingOne private IP ↔ one public IPMany private IPs → one public IP
DirectionInbound and outboundOutbound only (responses allowed, initiations blocked)
Public IP typeElastic IP or dynamic public IPElastic IP (static, does not change)
ResilienceRegion-resilient (one per VPC)AZ-resilient only (one per AZ for full HA)

How to Set Up NAT Gateway

  1. Provision the NAT Gateway in a public subnet — it needs access to the IGW to reach the internet.
  2. Assign an Elastic IP to the NAT Gateway — this is the public IP it presents to the internet.
  3. In the private subnet's route table, set the default route (0.0.0.0/0) to point at the NAT Gateway.

When a private instance sends a packet, the VPC router forwards it to the NAT Gateway. The NAT Gateway records the connection in its translation table, replaces the source IP with its own private IP, and passes the packet to the IGW. The IGW then translates that to the Elastic IP. Responses follow the same path in reverse.

High Availability Design

A NAT Gateway is AZ-resilient — it can survive hardware failures within an AZ but goes down if the entire AZ fails. For region-level resilience, deploy one NAT Gateway per AZ and configure each AZ's private subnets to use the NAT Gateway in their own AZ:

AZPublic subnetNAT GatewayPrivate subnet route
eu-west-1apublic-anat-a (EIP-A)0.0.0.0/0 → nat-a
eu-west-1bpublic-bnat-b (EIP-B)0.0.0.0/0 → nat-b
eu-west-1cpublic-cnat-c (EIP-C)0.0.0.0/0 → nat-c
Exam tip
If all private subnets route to a single NAT Gateway and that AZ fails, all private instances lose outbound internet access even though their own AZs are healthy. Deploy one NAT Gateway per AZ for full resilience.

Exam tip
NAT gateways do not work with IPv6. IPv6 addresses are publicly routable — private instances with IPv6 can route directly through an IGW (or use an Egress-Only IGW for outbound-only IPv6). NAT is only needed for IPv4.
