VPC Basics

Virtual Private Cloud (VPC) Basics

9 lessons · ~80 min total

Source: Adrian Cantrill SAA-C03 · AWS VPC User Guide

This module covers the foundational networking layer of AWS. Every service you deploy lives inside (or connects to) a VPC, so a firm grasp of VPC concepts is essential for the SAA-C03 exam and for real-world architecture work.

# Lesson Key idea
01 Custom VPCs Region-resilient, CIDR /28–/16, DNS flags enableDnsSupport & enableDnsHostnames
02 VPC Subnets AZ-resilient, 5 reserved IPs per subnet, DHCP options sets are immutable
03 VPC Routing & Route Tables Longest-prefix-match, local target wins ties, main vs custom route tables
04 Internet Gateway (IGW) Region-resilient, max 1 per VPC, static NAT — OS never sees public IP
05 Bastion Hosts Jump box in public subnet for SSH/RDP to private instances
06 Stateful vs Stateless Firewalls Stateless (NACL) needs 2 rules per connection; stateful (SG) auto-allows responses
07 Network ACLs (NACLs) Subnet boundary, stateless, numbered rules, only tool that can explicitly deny by IP
08 Security Groups ENI-level, stateful, allow-only, can reference other SGs and itself
09 NAT & NAT Gateway Many-to-one outbound-only; AZ-resilient; deploy one per AZ for HA; no IPv6
Exam scope
The SAA-C03 exam regularly tests the difference between NACLs and Security Groups (stateful vs stateless, explicit deny vs implicit), NAT Gateway HA design, and the six steps to make a subnet public. These are the highest-yield topics in this module.
