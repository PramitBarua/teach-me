Lesson 01 of 09 · ~8 min

What is a VPC?

A Virtual Private Cloud (VPC) is a regionally isolated, regionally resilient private network inside AWS. When you create a VPC it operates across all Availability Zones in that region, but nothing flows in or out without explicit configuration. Each VPC is its own isolated blast radius — a misconfiguration or breach in one VPC cannot automatically affect another.

You can create multiple VPCs in one account. The default VPC is created automatically by AWS; everything else is a custom VPC that you design from scratch.

Tenancy and CIDR Allocation

When you create a custom VPC you make two foundational choices:

ChoiceOptionsKey implication
Tenancy Default / Dedicated Dedicated forces every resource in the VPC onto dedicated physical hardware — expensive and hard to undo
IPv4 CIDR block /28 (16 IPs) → /16 (65,536 IPs) The CIDR range cannot overlap with other VPCs you intend to connect; plan carefully

A VPC always has one mandatory primary private IPv4 CIDR block. You can add optional secondary CIDR blocks later. By default, all addressing inside the VPC uses private IP space; public IPs are an overlay assigned at the subnet level.

Exam tip
The allowed CIDR sizes are /28 (smallest, 16 IPs) and /16 (largest, 65,536 IPs). Any prefix outside that range is rejected at creation time.

DNS Inside a VPC

AWS provides a fully-featured DNS resolver for every VPC, powered by Route 53. The DNS address is always the base IP of the VPC + 2. For example, if your VPC CIDR starts at 10.0.0.0, the DNS resolver lives at 10.0.0.2.

Two VPC-level settings control DNS behaviour:

SettingWhat it controlsDefault in custom VPC
enableDnsSupport Whether the VPC DNS resolver is active and reachable at base+2 true
enableDnsHostnames Whether instances with public IPs receive public DNS hostnames false (must be enabled manually)
Exam tip
If you need EC2 instances to receive public DNS names (e.g. ec2-54-x-x-x.compute-1.amazonaws.com), you must enable both enableDnsSupport and enableDnsHostnames on the VPC.
