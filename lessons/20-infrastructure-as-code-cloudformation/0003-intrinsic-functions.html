Intrinsic Functions

Lesson 03 of 17 · ~11 min

Source: Adrian Cantrill SAA-C03 · Intrinsic function reference · Fn::GetAtt · Fn::Cidr

Everything so far — logical resources, template parameters, pseudo parameters — has been either static or supplied as input. Intrinsic functions are different: they let a template take actions and pull values at runtime, while the stack is actually being created. That runtime awareness is a big part of what makes templates portable.

Ref and Fn::GetAtt: Referencing Other Things

Every parameter and every logical resource has a main value. For a parameter, it's simply the value provided. For a logical resource, it's usually the physical resource ID — once that resource reaches create complete. The Ref function retrieves this main value, and it's how a subnet's logical resource can point at a VPC's logical resource, or how a resource can pick up a parameter's value.

Properties:
  ImageId: !Ref LatestAmiIdParameter
  InstanceType: t3.micro

Some resources also expose secondary attributes beyond their main value — an EC2 instance's public IP address or public DNS name, for example. Fn::GetAtt retrieves these, taking the logical resource name and the attribute name:

WebsiteUrl: !GetAtt MyInstance.PublicDnsName

Ref and Fn::GetAtt are the two functions you'll reach for constantly — almost every non-trivial template uses both.

Fn::GetAZs and Fn::Select: Staying Region-Agnostic

Hard-coding an Availability Zone name like us-east-1a defeats portability the moment the template runs in a different Region. Fn::GetAZs returns the list of AZs available in a given Region (or the Region the stack is being created in, if left blank), and Fn::Select picks a single item out of that list by a zero-based index.

AvailabilityZone: !Select [0, !GetAZs '']
A default-VPC nuance
Fn::GetAZs doesn't quite return every AZ that exists in a Region — it returns AZs where the account's default VPC has a subnet. Normally that's the same thing as "every AZ," but if the default VPC has had subnets deleted from it, the list you get back can be incomplete. Worth knowing if the AZ list ever looks shorter than expected.

Fn::Join and Fn::Split: Strings and Lists

Fn::Split takes a single delimited string and turns it into a list; Fn::Join does the reverse, combining a list into one string using a delimiter. A common use is building a usable URL out of a protocol string and an instance's DNS name attribute:

SiteUrl: !Join ['', ['https://', !GetAtt MyInstance.PublicDnsName]]

Fn::Base64 and Fn::Sub: Encoding and Substitution

Plenty of AWS inputs — EC2 user data among them — must be Base64-encoded. Fn::Base64 accepts plain text and outputs the Base64 form the target resource actually needs. Fn::Sub does variable substitution: write ${VariableName} inside a string, and Fn::Sub replaces it with the runtime value of a parameter, a resource's main value, or a Logical.Attribute pair.

One restriction worth remembering
A resource can't use Fn::Sub to reference its own attributes — an instance's user data can't substitute in that same instance's own instance ID, because the physical resource doesn't exist yet at the point the substitution would need to happen.

Fn::Cidr: Automatic Subnet Ranges

Instead of manually carving up a VPC's CIDR range into subnet ranges by hand, Fn::Cidr takes a parent CIDR block, a count of ranges to generate, and the size of each range, then returns a list of CIDR blocks you can hand out with Fn::Select. It's limited to working within the parent VPC's range — it can't allocate or reclaim address space outside it — but for straightforward subnetting it removes a whole category of manual arithmetic.

Still to come

Stale vs. current: three newer intrinsic functions
Since this course was recorded, AWS added Fn::ForEach, Fn::Length, and Fn::ToJsonString as part of the AWS::LanguageExtensions transform (a template must opt in with that transform to use them). Fn::ForEach is a genuine loop construct — it repeats a fragment of a template once per item in a collection, which is a real capability gap the original function list didn't cover. Fn::Length returns the size of an array, and Fn::ToJsonString converts a template fragment into an escaped JSON string. None of them replace Ref, Fn::GetAtt, or the other functions above — they're additions, not corrections.
