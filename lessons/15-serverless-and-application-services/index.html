Serverless & Application Services

22 lessons · ~178 min total

Source: Adrian Cantrill SAA-C03 · AWS Lambda Developer Guide · Amazon SQS Developer Guide

The largest module in the course so far: how architectures evolve from monoliths toward decoupled, event-driven, serverless designs, and the full catalog of AWS services that implement each piece of that picture — compute (Lambda), eventing (EventBridge, SNS, Step Functions), API delivery (API Gateway), queuing (SQS), streaming (Kinesis), identity (Cognito), and integration (Glue, Amazon MQ, AppFlow).

Exam scope
The highest-yield material here is Lambda's networking and permissions model (execution role vs. resource-based policy, VPC cold-start implications), the SQS visibility timeout / dead-letter queue mechanics, SNS fan-out as the standard decoupling pattern, and Cognito user pools vs. identity pools — one of the most frequently confused pairs on the exam. Also worth knowing cold: several products in this module have been renamed or restructured since the course was recorded (EventBridge, Amazon Data Firehose, Managed Service for Apache Flink) — the underlying architecture reasoning the exam tests hasn't changed, only the branding.
