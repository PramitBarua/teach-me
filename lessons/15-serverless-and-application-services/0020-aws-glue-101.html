AWS Glue 101

Lesson 20 of 22 · ~8 min

Source: Adrian Cantrill SAA-C03 · What Is AWS Glue? · Data Discovery and Cataloging in AWS Glue

AWS Glue is a serverless ETL (extract, transform, load) service: it moves and reshapes data between sources and destinations without you provisioning any compute. This lesson stays at the architectural level — enough for the exam, no deeper.

What Glue Moves, and Where

Source data stores
S3, RDS, DynamoDB, and any JDBC-compatible database (Redshift and others).
Source streams
Kinesis Data Streams, Apache Kafka.
Targets
S3, RDS, and JDBC-compatible databases.

Because Glue is serverless, AWS provisions and manages the compute pool that runs your jobs — you only pay for what a job actually consumes while it runs.

The Data Catalog: Metadata Without Silos

A data catalog is persistent metadata about your data — its structure, location, and format — combined with tools to search and manage it. AWS Glue provides exactly one data catalog per region, per account.

Crawlers are the mechanism that populates it: point one at a data source with the right credentials, and it connects, infers the schema, and writes the resulting metadata into the catalog. Once that's done, data that would otherwise sit siloed inside one team's S3 bucket or database becomes visible and usable across the whole organization — a finance team can discover and query data a completely different team gathered, without ever touching the source system directly.

Who actually reads the Data Catalog
Athena, Redshift Spectrum, EMR, and AWS Lake Formation all use the Glue Data Catalog as their source of schema metadata. Seeing any of these products alongside "schema discovery" in a question is a strong signal the answer involves Glue's catalog.

Glue Jobs: The ETL Part

A Glue job extracts data from a source, runs it through a transformation script you write, and loads the result into a destination — all on a serverless, AWS-managed compute pool. Jobs can be started manually, triggered by other events, or run on an EventBridge schedule.

ComponentRole
CrawlerConnects to a source, infers schema, populates the Data Catalog
Data CatalogPersistent, organization-wide metadata store — one per region, per account
Glue JobServerless ETL: extract, transform via script, load into a destination

Glue vs. Data Pipeline

AWS Data Pipeline is an older ETL product that provisions EMR clusters inside your account to do the work — it is not serverless. In an exam question that mentions both, keywords like serverless, ad hoc, or cost-effective point to Glue.

Current state: Data Pipeline is closed to new customers
As of July 2024, AWS Data Pipeline no longer accepts new customers — existing users can keep running it, but AWS is directing all new ETL workloads toward Glue. What the source material frames as a future prediction is now simply the current state: for any new design, Glue is the default answer, and Data Pipeline should only appear in questions about legacy systems already using it.
