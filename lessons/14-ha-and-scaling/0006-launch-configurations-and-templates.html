Launch Configurations and Launch Templates

Lesson 06 of 12 · ~5 min

Source: Adrian Cantrill SAA-C03 · Auto Scaling Launch Templates · Auto Scaling Launch Configurations

Before an Auto Scaling group (next lesson) can launch anything, it needs a definition of what to launch: AMI, instance type/size, storage, key pair, networking and security groups, user data, and IAM role — everything you'd normally specify when launching an instance by hand. That definition lives in either a launch configuration or a launch template.

Launch ConfigurationLaunch Template
Editable after creation?NoNo, but supports versions
Can be used to launch instances directly (console/CLI)?No — ASG onlyYes
Supports mixed instance types / Spot+On-Demand in one ASG?NoYes
Supports newer features (T2/T3 Unlimited, placement groups, capacity reservations, Elastic Graphics)?NoYes

Neither is editable once created — if you need a different configuration, you create a new one (or, for launch templates, a new version) and point the Auto Scaling group at it.

Current AWS state: launch configurations are being phased out
This lesson's source material presents launch templates as simply the newer, richer option. As of when this lesson was written, AWS has gone further: accounts created on or after June 1, 2023 can no longer create launch configurations via the console, and accounts created on or after October 1, 2024 cannot create them at all — console, API, CLI, or CloudFormation. Launch templates are now the only path for new work. See Auto Scaling launch configurations for the current deprecation status. You may still see launch configurations referenced in exam questions describing legacy environments, so it's worth knowing they exist — just don't expect to create one in a modern account.
Exam tip
Launch configurations/templates control the what — the instance definition. The Auto Scaling group (next lesson) controls the when and where — when instances launch, and which subnets they go into. Keep that split clean; it's an easy way to eliminate wrong answers quickly.
