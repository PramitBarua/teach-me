Advanced EC2

Advanced EC2

8 lessons · ~60 min total

Source: Adrian Cantrill SAA-C03 · Amazon EC2 User Guide

This module builds on EC2 basics with the automation, security, monitoring, and performance features a solutions architect needs for real deployments: bootstrapping instances at launch, giving them safe AWS permissions, storing their configuration and secrets centrally, capturing their internal logs, and controlling their physical placement and networking performance.

# Lesson Key idea
01 EC2 Bootstrapping with User Data User data runs once at launch, opaque to EC2; boot-time-to-service-time and the bake-vs-bootstrap trade-off
02 cfn-init and Creation Policies Desired-state config via AWS::CloudFormation::Init; CreationPolicy + cfn-signal for resource completion reporting
03 EC2 Instance Roles and Profiles Instance profile as the wrapper that attaches an IAM role to an instance; auto-renewing metadata credentials
04 SSM Parameter Store String/StringList/SecureString parameters, hierarchical paths, KMS encryption, AWS public parameters
05 System and Application Logging on EC2 CloudWatch agent for OS-level visibility; one log group per log file, one log stream per instance
06 EC2 Placement Groups Cluster (performance), spread (7-per-AZ isolation), and partition (isolation at scale) strategies
07 EC2 Dedicated Hosts Whole-host allocation for per-socket/core licensing; fixed-size vs. Nitro mixed-size hosts
08 Enhanced Networking and EBS-Optimized Instances SR-IOV for bandwidth/PPS/latency; dedicated EBS network capacity for consistent storage performance
Exam scope
The highest-yield details here are the instance profile vs. IAM role distinction (Lesson 03), the 7-instances-per-AZ limit on spread placement groups versus partition placement groups' partition-based scaling (Lesson 06), and knowing user data runs once while cfn-init can respond to stack updates (Lessons 01–02) — all classic "which option actually does X" scenario traps.
