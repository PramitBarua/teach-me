Simple Storage Service (S3)

S3 Storage Classes — Part 1

Lesson 08 of 16 · ~8 min

Source: Adrian Cantrill SAA-C03 · S3 Storage Classes Overview

This lesson covers the three "warm" storage classes. Part 2 covers Glacier tiers and Intelligent-Tiering.

S3 Standard

The default general-purpose class. Objects are replicated across 3 Availability Zones in the region, giving high durability (11 nines) and availability.

  • Latency: milliseconds (first-byte latency)
  • Retrieval fee: none
  • Minimum duration: none
  • Minimum object size: none
  • Use for: frequently accessed, important, non-replaceable data

S3 Standard-IA (Infrequent Access)

Same durability and availability as Standard (3 AZ), same millisecond latency, but optimised for data that is accessed infrequently.

  • Storage cost: cheaper than Standard
  • Retrieval fee: per-GB charge on every retrieval (increases cost for frequent access)
  • Minimum duration: 30 days — even if you delete early, you are billed for 30 days
  • Minimum object size: 128 KB — small objects are charged as 128 KB each
When NOT to use Standard-IA
Do not store frequently accessed data (retrieval fees make it expensive), short-lived data (30-day minimum billing), or many tiny files (128 KB minimum charge per object inflates cost).

S3 One Zone-IA

Same characteristics as Standard-IA — retrieval fee, 30-day minimum, 128 KB minimum — but data is stored in only one AZ. Durability is still 11 nines within that AZ, but if the AZ fails, the data is lost.

  • Storage cost: cheaper than Standard-IA
  • Use for: non-critical, reproducible data that you do not access often

Exam tip
Standard-IA is designed for data you need instantly but rarely — "once a month" is a good mental model. One Zone-IA is the same but with the trade-off of reduced resilience for lower cost.

Retrieval Practice

1. An object stored in S3 Standard-IA is deleted after 10 days. How many days are billed?

2. Which storage class would you choose for data that must survive an entire Availability Zone failure?

3. A system stores 50,000 thumbnail images averaging 20 KB each in S3 Standard-IA. Why might this be a poor fit?
