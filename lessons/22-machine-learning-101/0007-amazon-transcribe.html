Amazon Transcribe

Lesson 07 of 11 · ~5 min

Source: Adrian Cantrill SAA-C03 · What is Amazon Transcribe?

Amazon Transcribe is an automatic speech recognition (ASR) service. The input is audio containing speech; the output is text. It's a deliberately narrow product, so there isn't a large amount of theory to hold onto — the value is in knowing what it does and recognizing when an exam scenario is describing it.

Core Features

Beyond the basic audio-to-text conversion, Transcribe offers a handful of features that improve the quality and safety of its output:

  • Language customization — specify the source language explicitly, or let Transcribe auto-detect it.
  • Content filtering — remove or mask profanity, or redact personally identifiable information (PII), so transcripts are safe to store or share.
  • Speaker identification — attribute segments of the transcript to different speakers in the same audio.
  • Custom vocabularies and custom language models — tune recognition for domain-specific terms (product names, jargon, acronyms) that a general-purpose model wouldn't reliably catch.

Billing is pay-per-use, charged per second of audio transcribed.

What the Console Demo Shows

A live walkthrough of the Transcribe console mostly confirms the theory rather than adding new concepts. Using real-time streaming transcription, spoken audio appears as text almost immediately, with a full transcript downloadable afterward. The console also surfaces the feature set described above as configurable settings: choosing or auto-detecting the source language, toggling speaker identification, applying vocabulary filtering or PII redaction, and — under a customizations section — supplying a custom vocabulary, enabling partial result stabilization, or attaching a custom language model. The console also exposes application integration options, and a menu for the product variants covered next.

Product Variants

Amazon Transcribe comes in a few flavors:

Amazon Transcribe (standard)
General-purpose speech-to-text, as described above.
Amazon Transcribe Medical
A variant tuned for medical speech and terminology.
Amazon Transcribe Call Analytics
Ingests audio from phone calls and layers on summarization, categorization, and sentiment analysis of the people talking.
Exam heuristic
"Speech to text" points to Transcribe. This is the mirror image of Amazon Polly, covered earlier in this module, which goes the other direction — text to speech. If a scenario describes converting spoken audio into written text, Transcribe is almost always the answer; if it describes generating spoken audio from text, think Polly instead.

Use Cases and Integration

Common uses for Transcribe include full-text indexing and search of audio content, generating meeting notes from recorded meetings, and producing subtitles, captions, or transcripts for video. It integrates with custom applications through its API, and — just as importantly — it's often the first step in a larger pipeline: transcribed text can be fed into other AWS machine learning services, such as Amazon Comprehend, for further analysis like sentiment detection.
