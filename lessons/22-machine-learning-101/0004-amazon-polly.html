Amazon Polly

Lesson 04 of 11 · ~4 min

Source: Adrian Cantrill SAA-C03 · Choosing a voice engine — Amazon Polly · Generative voices — Amazon Polly

Amazon Polly converts text into lifelike speech. Feed it "I like cats, dogs, chickens and rabbits, spiders, not so much," and it produces spoken audio of that exact sentence. The key restriction to remember: Polly performs no translation. Input text in a given language always comes out as speech in that same language — it never converts between languages.

Synthesis Modes

The source course describes two modes of speech synthesis:

Standard TTS (text-to-speech)
Uses a concatenative architecture, built from phonemes — the smallest units of sound (the phoneme for the letter A, for instance). Speech is assembled by stitching these units together.
Neural TTS
Takes phonemes, generates spectrograms from them, and passes those through a vocoder to produce the output audio. This is far more computationally expensive than standard TTS, but produces noticeably more natural, human-sounding speech.
A newer tier: generative voices
Since this course content was recorded, AWS has added a third synthesis tier: generative voices. Built on a larger model than standard or neural TTS, generative voices aim for the most human-like, emotionally engaged, and adaptive speech Polly offers — better handling of context-dependent prosody, pausing, and natural delivery. Conceptually it slots in as a step beyond neural TTS on the same "more compute, more natural" spectrum: standard → neural → generative.

Output Formats and SSML

Polly can output MP3, Ogg Vorbis, or PCM. The choice depends on how you're integrating Polly elsewhere — PCM, for instance, is a common pick when feeding raw audio into another AWS product rather than playing an audio file directly.

Polly also supports SSML (Speech Synthesis Markup Language), which lets you control delivery within the text itself: emphasizing certain words, controlling pronunciation, whispering parts of a sentence, or applying an exaggerated newscaster speaking style.

Integration component, not a standalone tool
Polly is almost always used as part of something else — a WordPress plugin that reads articles aloud, another AWS service needing generated speech, or a custom application calling the API — rather than something used on its own. If a scenario needs text turned into spoken audio, in the same language, that's Polly.
