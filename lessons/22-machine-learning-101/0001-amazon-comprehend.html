Amazon Comprehend

Lesson 01 of 11 · ~5 min

Source: Adrian Cantrill SAA-C03 · Amazon Comprehend insights overview · Detecting PII entities

Amazon Comprehend is a natural language processing service: you feed it a document — in practice, just text — and it surfaces the important elements buried inside it. This is the first of a run of "pre-built AI service" lessons. Each one wraps a common, well-defined AI task behind a managed API, so you get the capability without needing any machine learning expertise. Contrast that with SageMaker, covered at the end of this module, which is for building genuinely custom models. If a scenario needs a specific, common task done via API with no ML background required, one of these services is probably the answer.

What Comprehend Extracts

Given an input document, Comprehend can identify:

  • Entities — people, organizations, locations, and other named things in the text.
  • Key phrases — the notable phrases that summarize what the text is about.
  • Language — which language the text is written in.
  • Sentiment — an overall reading of positive, negative, neutral, or mixed tone.
  • PII (personally identifiable information) — names, credit card numbers, bank details, addresses, phone numbers, emails, and similar sensitive fields.

Every one of these results comes back with a confidence score from 0 to 1 (0% to 100%), showing how sure Comprehend is about that particular finding. A person entity might come back at 0.99+, meaning Comprehend is over 99% confident that piece of text really is a person's name.

The keyword heuristic
If an exam scenario mentions sentiment analysis, entity recognition, key phrase extraction, or detecting PII within text, default to Comprehend.

Pre-Trained or Custom, Real-Time or Batch

Comprehend is a machine learning service built on either pre-trained models (the built-in analysis type, ready to use immediately) or custom models you train to fit your own data. It supports two ways of running analysis: real-time (synchronous) analysis for small inputs, where you get results back immediately, and asynchronous batch jobs for larger workloads, where you submit a job and it processes in the background. It's accessible from the console or CLI for interactive, one-off use, and via the API for integrating the capability directly into an application.

What the Console Demo Shows

The console's built-in sample lets you paste in text and click analyze. Feeding it a sample email containing a name, a company, a credit card number, and an address produces exactly the categories above: entities (person, organization, location, and a generic "other" category for things like credit card numbers and email addresses), key phrases, detected language, PII findings, and an overall sentiment reading. Changing the input text changes the sentiment result in an intuitive way — mentioning something you like alongside something you dislike shifts the reading from purely positive or negative toward mixed. The conceptual takeaway isn't the UI itself; it's that all of this — sentiment, key phrases, entities, PII — comes from the same document in a single pass, and the exact same categories are available through the API for use inside a real application.
