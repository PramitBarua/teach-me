Machine Learning 101

Machine Learning 101

11 lessons · ~58 min total

Source: Adrian Cantrill SAA-C03 · AWS AI Services Overview

A survey of AWS's pre-built AI services — ten managed products that each solve one common AI task via API, no ML expertise required — followed by Amazon SageMaker, the platform for building genuinely custom models when none of the ten pre-built services fit. Each lesson here is intentionally short: the exam (outside the ML Specialty track) only needs a high-level architectural understanding of each product, not implementation depth.

# Lesson Key idea
01Amazon ComprehendNLP on text: entities, key phrases, language, sentiment, PII — each with a confidence score
02Amazon KendraIntelligent enterprise search that mimics a human expert, resolving question intent — closing to new customers
03Amazon LexConversational chatbots/voice (powers Alexa): ASR + NLU, intents/utterances/slots, Lambda fulfillment
04Amazon PollyText-to-speech only, no translation; standard/neural/generative voice tiers; SSML for delivery control
05Amazon RekognitionDeep learning image/video analysis: objects, faces, text, moderation, activity, live video via Kinesis
06Amazon TextractExtracts text, tables, and relationships from documents; normalizes ID fields across document types
07Amazon TranscribeSpeech-to-text (the reverse of Polly); Transcribe Medical and Call Analytics variants
08Amazon TranslateNeural text-to-text translation via encoder/decoder/attention; often one step in a larger pipeline
09Amazon ForecastTime-series forecasting with explainability — closed to new customers since July 2024
10Amazon Fraud DetectorOnline Fraud / Transaction Fraud / Account Takeover model types — closed to new customers since Nov 2025
11Amazon SageMakerThe build-your-own-model counterpart to the ten services above: Studio, Domains, containers, hosting
Exam scope
Almost every lesson here reduces to a single keyword-matching heuristic: sentiment/entities/PII-in-text → Comprehend; enterprise document search → Kendra; chatbot/voice assistant → Lex; text-to-speech → Polly; image/video analysis → Rekognition; extract text/tables from documents → Textract; speech-to-text → Transcribe; text-to-text translation → Translate; time-series forecasting → Forecast; fraud scoring → Fraud Detector. The one non-keyword distinction that matters most: a scenario needing a genuinely custom model, rather than one of these ten pre-built tasks, points to SageMaker instead.
Several of these services have real, dated lifecycle changes — independently verified, not just taken on faith
Amazon Kendra closes to new customers July 30, 2026 (Maintenance Mode since June 30, 2026); AWS now points new search/RAG work to Amazon Bedrock Knowledge Bases (Lesson 02). Amazon Rekognition's Streaming Video Analysis and Bulk Image Analysis closed to new customers April 30, 2026 (Lesson 05). Amazon Forecast closed to new customers July 29, 2024, with AWS steering new projects to SageMaker Canvas (Lesson 09). Amazon Fraud Detector closed to new customers November 7, 2025, with AWS recommending SageMaker, AutoGluon, or AWS WAF Fraud Control instead (Lesson 10). And Amazon SageMaker itself was renamed "Amazon SageMaker AI" in December 2024, repositioned as one part of a broader unified data/AI platform alongside SageMaker Unified Studio and Amazon Bedrock (Lesson 11). Each lesson still teaches the underlying architecture the exam tests, but flags its own status change plainly rather than presenting a closed-to-new-customers product as fully current.
