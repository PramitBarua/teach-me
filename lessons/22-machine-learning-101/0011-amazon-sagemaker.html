Amazon SageMaker

Lesson 11 of 11 · ~8 min

Source: Adrian Cantrill SAA-C03 · What is Amazon SageMaker? · Amazon SageMaker AI domains

Every other service in this module — Comprehend, Kendra, Lex, Polly, Rekognition, Textract, Transcribe, Translate, Forecast, Fraud Detector — is a pre-built AI capability: you send in data and get back a result, with no model of your own to build or train. Amazon SageMaker is this module's counterpart to all of that: it's the platform you reach for when you need to build, train, and host a genuinely custom machine learning model rather than consume someone else's.

A Platform for the Whole ML Lifecycle

SageMaker isn't one single product — it's a collection of products and features packaged together as a fully managed machine learning service. It covers the entire lifecycle of a model: fetching, cleaning, and preparing data; training and evaluating models; deploying them; and then monitoring them and collecting data on how they perform in production.

Key Concepts

SageMaker Studio
An IDE — an integrated development environment — for the entire ML lifecycle. It's where you build, train, debug, and monitor models, all from one development environment.
SageMaker Domain
Isolation and grouping for a particular project. Creating a domain provisions the surrounding infrastructure a project needs: an EFS volume, users, applications, policies, and VPC configuration. You must create a domain before you can start using SageMaker at all — think of it as the container a project lives inside.
Containers
SageMaker workloads run as Docker containers deployed onto purpose-built ml.-prefixed EC2 instance types, sized and designed specifically for machine learning work. Many pre-built containers exist, each shipped with specific versions of the OS, libraries, and tooling suited to a particular ML task.
Hosting
Once a model is trained, SageMaker can deploy it as an endpoint that applications call to get predictions — using either serverless or continuously running compute architectures, depending on the workload.
Cost awareness: SageMaker itself is free, its resources are not
SageMaker has no charge of its own — but every resource it provisions (compute, storage, endpoints) does, and machine learning workloads are often resource-intensive. Costs can scale up quickly, and pricing is fairly complex given the range of resource types SageMaker can create. Treat "no SageMaker charge" as a fact about the control plane, not a promise about the bill.
A modern evolution: SageMaker as a unified platform
Since this course was recorded, AWS renamed the original product to Amazon SageMaker AI and repositioned "Amazon SageMaker" as a broader umbrella: a unified platform for data, analytics, and AI. Under that umbrella now sit SageMaker AI (the model build/train/deploy service described above), SageMaker Lakehouse, SageMaker Unified Studio (a single development environment spanning analytics and AI tooling), and Amazon Bedrock — positioned as SageMaker's sibling product for foundation-model and generative-AI use cases. The core concepts this lesson teaches — Studio, Domain, containers, and hosting — remain the exam-relevant foundation; the branding around them has simply grown a layer.

Exam Heuristic

If a scenario describes a task a pre-built AI service already handles — text extraction, translation, speech, sentiment, forecasting, fraud scoring — reach for the specific service built for it. If the scenario genuinely calls for developing, training, or hosting a custom model, that's SageMaker. This module, start to finish, is really that one distinction: ten ready-made answers, and one platform for building your own.
