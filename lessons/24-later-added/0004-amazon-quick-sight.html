Amazon Quick (formerly QuickSight)

Lesson 4 of 23 · ~6 min

Source: What is Quick? · Importing data into SPICE · QuickSight evolves to Quick Suite

Analytics pipelines in this course end in S3, Athena, Redshift or a database. Someone still has to turn those tables into charts that business users can read. That's business intelligence (BI), and AWS's serverless BI service was Amazon QuickSight.

The name changed
In October 2025, QuickSight was folded into a broader product, Amazon Quick Suite, which has since been shortened to Amazon Quick. That's how the current SAA-C03 in-scope list names it. The classic BI dashboards are now the Quick Sight capability inside it. Quick also adds AI agent features (chat, research, flows and automation), but for this exam, think "QuickSight dashboards". Questions may use either name.

What Quick Sight Does

Serverless BI
You don't run servers or BI software. You connect data sources, build analyses, and publish interactive dashboards for business users.
Data sources
AWS sources such as Athena, Redshift, RDS and Aurora, and S3, plus uploaded files and third-party SaaS and databases.
Embedded analytics
Dashboards can be embedded in your own web applications for your customers.
Users
Provisioned through IAM Identity Center or IAM federation (see Lesson 1).

SPICE: Why Dashboards Get Fast and Cheap

For each dataset you choose between a direct query against the source and importing the data into SPICE (Super-fast, Parallel, In-memory Calculation Engine). With SPICE:

  • Queries run faster because the data is held in memory. You don't wait on the source system.
  • The source isn't hit on every dashboard view. If the source charges per query (Athena, for example), you pay only when the dataset is created and when it's refreshed.
  • SPICE capacity is allocated per AWS Region. In Enterprise edition, SPICE data is encrypted at rest.
Which dashboard service?
Business users, sales or finance dashboards, BI, embedded analytics: Quick (QuickSight). Operational metrics from Prometheus, CloudWatch or X-Ray: Managed Grafana (Lesson 19). Log search and exploration: OpenSearch Dashboards (Lesson 3). A classic serverless pipeline is S3, then the Glue Data Catalog, then Athena, then Quick Sight.
