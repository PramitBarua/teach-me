AWS Network Firewall and AWS Firewall Manager

Lesson 15 of 23 · ~7 min

Source: What is AWS Network Firewall? · AWS Firewall Manager

You already have four layers of network protection: security groups (stateful, per ENI), NACLs (stateless, per subnet), WAF (HTTP layer 7, on ALB, CloudFront or API Gateway) and Shield (DDoS). Something is still missing: a real firewall for a whole VPC's traffic, one that inspects every protocol and filters by domain name. That's Network Firewall. And once you have dozens of accounts, you need one place to roll all of these out. That's Firewall Manager.

AWS Network Firewall

What it is
A managed, highly available, stateful network firewall and intrusion detection and prevention (IDS/IPS) service for your VPCs. It scales automatically with traffic.
How traffic reaches it
You deploy firewall endpoints into dedicated firewall subnets, one per AZ, then change route tables so traffic passes through the endpoint. It can sit in front of internet gateway, NAT gateway, Transit Gateway, VPN and Direct Connect traffic.
What it can filter
Stateless and stateful rules: 5-tuple rules, domain lists (allow or deny *.example.com, including by TLS SNI), and Suricata-compatible IPS signatures that inspect packet contents.
Central inspection pattern
Put Network Firewall in an inspection VPC attached to a Transit Gateway, so all east-west and egress traffic from many VPCs is inspected in one place.

AWS Firewall Manager

Firewall Manager is a central policy service for AWS Organizations. You define a policy once, and it is applied to every in-scope account and resource. Accounts and resources added later are covered automatically. It manages:

  • AWS WAF rules on ALBs, API Gateway and CloudFront
  • Shield Advanced protections
  • Security groups, including audits for overly permissive rules, and NACLs
  • Network Firewall deployments
  • Route 53 Resolver DNS Firewall rules

Prerequisites: the account must be in AWS Organizations, a Firewall Manager administrator account must be designated, and AWS Config must be enabled.

NeedService
Block SQL injection or XSS on an ALBWAF
Filter all VPC egress by domain, or deep packet inspection and IPSNetwork Firewall
Apply WAF, security group or firewall rules across every account automaticallyFirewall Manager
Keywords
"Inspect all traffic leaving the VPC", "allow-list outbound domains", "intrusion prevention", "stateful inspection between VPCs through a Transit Gateway": Network Firewall. "Centrally enforce WAF and security group rules in all accounts, including new ones": Firewall Manager. Firewall Manager doesn't inspect traffic itself. It deploys and audits the services that do.
