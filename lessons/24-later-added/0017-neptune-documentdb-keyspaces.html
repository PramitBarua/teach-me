Purpose-Built Databases: Neptune, DocumentDB, Keyspaces

Lesson 17 of 23 · ~7 min

Source: What is Amazon Neptune? · What is Amazon DocumentDB? · What is Amazon Keyspaces?

The course went deep on RDS, Aurora, DynamoDB, ElastiCache and Redshift. The exam also expects you to recognize three more purpose-built databases. Each is a managed, AWS-compatible home for a specific open-source data model. You almost never need their internals. You need the trigger word that points to each one.

Amazon Neptune: Graph

A fully managed graph database that stores relationships as first-class data and queries them with Gremlin, openCypher or SPARQL. Use it for social networks, recommendation engines, fraud detection (rings of linked accounts) and knowledge graphs. These are queries like "friends of friends who bought X" that would need many expensive joins in SQL. Like Aurora, it has a primary instance and up to 15 read replicas over a cluster volume replicated across AZs. Neptune Analytics adds in-memory graph analytics.

Amazon DocumentDB: MongoDB-Compatible Documents

A fully managed JSON document database that is MongoDB-compatible, so existing MongoDB drivers, applications and tools work with little or no change. Its architecture also looks like Aurora: storage is kept as six copies across three AZs, with up to 15 read replicas and point-in-time recovery. Elastic clusters shard for very large workloads.

Amazon Keyspaces: Cassandra-Compatible Wide-Column

A serverless, Apache Cassandra-compatible database. Existing Cassandra applications and drivers use CQL (Cassandra Query Language) as before, but there are no clusters or nodes to manage. Tables scale up and down automatically, with on-demand or provisioned capacity.

Compatibility questions are the most common
"Migrate an on-premises MongoDB database to a managed service with minimal code changes": DocumentDB. "Migrate Cassandra and stop managing nodes": Keyspaces. DynamoDB is the usual distractor in both. It's managed and NoSQL, but it would mean rewriting the data-access code.

Retrieval Practice

Answer from memory. Explanations appear after each answer.

1. A bank wants to spot fraud rings: groups of accounts linked through shared devices, addresses and payees, often several hops apart. Queries must traverse these connections in real time. Which database fits best?

2. A company runs a self-managed MongoDB cluster for its content platform. It wants a fully managed AWS database that is highly available across AZs, without rewriting its data-access layer. What fits?

3. An IoT platform runs on an Apache Cassandra cluster and uses CQL. The team is tired of managing nodes, compaction and scaling, and wants a serverless option without changing its queries. What should they choose?
