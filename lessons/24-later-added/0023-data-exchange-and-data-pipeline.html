AWS Data Exchange and AWS Data Pipeline

Lesson 23 of 23 · ~5 min

Source: What is AWS Data Exchange? · What is AWS Data Pipeline?

Two analytics services finish this module. Their names sound alike, but they do completely different jobs. One brings in other organizations' data. The other moves and transforms your own data on a schedule, and it's now closed to new customers.

AWS Data Exchange: Third-Party Data, Delivered

Data Exchange helps you find, subscribe to and use data from other organizations, for example financial market feeds, weather, demographics or healthcare reference data. Commercial data products are listed in the AWS Marketplace catalog. Organizations can also send each other data grants directly. The provider maintains the delivery and entitlement infrastructure; as a subscriber you just accept and use the data.

Data sets come in five types:

  • Files, exported into your S3 bucket;
  • APIs, called through API Gateway-backed endpoints;
  • Amazon Redshift datashares, queried read-only with no ETL;
  • Amazon S3 data access, used directly in the provider's bucket;
  • AWS Lake Formation permissions (in preview).

Open Data on AWS public data sets are also discoverable through it.

AWS Data Pipeline: Legacy, Closed to New Customers

Maintenance mode
AWS Data Pipeline is no longer available to new customers and is in maintenance mode. No new features or Region expansions are planned. Existing customers can keep using it, and AWS publishes migration guidance toward services such as AWS Glue, Step Functions and Amazon MWAA.

Data Pipeline automated the movement and transformation of data on a schedule, as a data-driven workflow in which each task can depend on earlier ones succeeding. A pipeline definition describes the business logic. The pipeline launches EC2 instances or EMR clusters to do the work, and a Task Runner polls for tasks and runs them. The classic example: copy web server logs to S3 every day, then run a weekly EMR job over them.

Keywords
"Subscribe to third-party data sets", "license commercial data and load it into S3 or Redshift": Data Exchange. "Scheduled, dependency-driven movement and ETL of your own data between AWS services": historically Data Pipeline. For a new design, prefer Glue (ETL) or Step Functions or MWAA (orchestration), unless the question explicitly names Data Pipeline.

Retrieval Practice

Answer from memory. Explanations appear after each answer.
