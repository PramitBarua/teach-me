AWS Elastic Beanstalk

Lesson 6 of 23 · ~8 min

Source: What is Elastic Beanstalk? · Elastic Beanstalk concepts · Deployment policies

You've built an EC2 web tier by hand: launch template, Auto Scaling group, ALB, health checks, CloudWatch alarms. Elastic Beanstalk builds all of that for you. You upload your application code, and Beanstalk provisions and manages the capacity, load balancing, scaling and health monitoring. Beanstalk itself costs nothing; you pay only for the resources it creates. You can still see and tune every one of those resources.

It supports common platforms out of the box, including Java, .NET, Node.js, PHP, Python, Ruby, Go and Docker.

Vocabulary

Application
The logical container, like a folder, for versions, environments and saved configurations.
Application version
A labeled iteration of deployable code, stored as an object in S3.
Environment
A running set of AWS resources that runs one application version at a time. "Prod" and "test" would be two environments.
Environment tier
Web server tier: serves HTTP requests behind a load balancer. Worker tier: pulls background jobs from an SQS queue, which offloads long-running work from the web tier.
Saved configuration
A reusable template of environment settings.

Deployment Policies

PolicyHow it worksTrade-off
All at onceDeploy to every instance at the same timeFastest, but causes downtime
RollingDeploy one batch at a timeNo downtime, but reduced capacity while a batch is out of service
Rolling with additional batchLaunch an extra batch first, then rollKeeps full capacity throughout
ImmutableLaunch a full set of new instances in a temporary ASG, then swapSlowest, but the safest rollback: just terminate the new instances
Traffic splittingSend a percentage of traffic to new instances (canary)Tests on live traffic; needs an ALB
Blue/greenDeploy to a separate environment, then swap environment URLs (a CNAME swap)Instant switch and rollback, but it's a DNS change
Spotting Beanstalk
"Developers want to deploy a web app without managing infrastructure but keep control of the underlying EC2 resources", or "upload code and AWS handles provisioning, load balancing and scaling": that's Elastic Beanstalk. For deployments: no downtime and full capacity means rolling with additional batch or immutable. Fastest rollback with no impact on the old version means immutable or blue/green. Background job processing means the worker tier with SQS.
