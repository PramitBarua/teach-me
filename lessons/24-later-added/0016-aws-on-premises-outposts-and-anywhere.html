Running AWS On-Premises: Outposts, ECS/EKS Anywhere, VMware Cloud on AWS

Lesson 16 of 23 · ~8 min

Source: What is AWS Outposts? · ECS Anywhere · EKS deployment options · VMware Cloud on AWS (Broadcom)

The Local Zones lesson introduced AWS's edge family: Local Zones (a Region extended near a city) and Wavelength (inside telecom 5G networks). This lesson covers the rest of that family. These are the ways to run AWS infrastructure, or AWS-managed orchestration, in your own data center. You'd do that for low latency to on-premises systems, local data processing, or data residency rules.

AWS Outposts: AWS Hardware in Your Building

Form factors
Outposts racks (full 42U racks) and Outposts servers (1U or 2U servers for space-limited sites). AWS delivers, installs, monitors, patches and maintains them.
How it connects
Each Outpost is anchored to an Availability Zone in a parent Region through a service link. It's an extension of that Region, and your VPC subnets can extend onto it. It needs reliable connectivity back to the Region for its control plane.
What runs on it
EC2, EBS, S3 on Outposts, ECS, EKS, RDS, EMR, ElastiCache and ALB. Support varies by form factor. You use the same APIs and console as in the Region.

VMware Cloud on AWS

VMware Cloud on AWS runs the VMware software-defined data center stack (vSphere, vSAN, NSX) on dedicated bare-metal AWS infrastructure. Companies with large VMware estates can migrate or extend into AWS, or use it for disaster recovery, without re-platforming VMs, while still reaching native AWS services. Since 2024 it has been sold by Broadcom (VMware's owner), not resold by AWS.

Pick the on-premises option
"AWS-managed infrastructure on premises using the same APIs, for low latency or data residency": Outposts. "Run ECS tasks on existing on-premises servers, managed from the ECS console": ECS Anywhere. "Kubernetes on premises with no connection to AWS": EKS Anywhere. "Move hundreds of VMware VMs with no changes, keeping VMware tools": VMware Cloud on AWS. "Single-digit-ms latency for mobile users on 5G": Wavelength.
