Amazon OpenSearch Service

Lesson 3 of 23 · ~6 min

Source: What is Amazon OpenSearch Service?

DynamoDB answers "fetch this item by key" very quickly. RDS answers relational SQL. Neither is good at "find every product whose description roughly mentions waterproof hiking boots", or at slicing a terabyte of logs by any field in real time. That's a search and analytics engine, and on AWS it's Amazon OpenSearch Service. It was called Amazon Elasticsearch Service before 2021, and it still runs legacy Elasticsearch versions up to 7.10.

What You Get

Domain
OpenSearch's word for a cluster: a set of data nodes, with optional dedicated master nodes for cluster stability, that you size by instance type and count.
High availability
Nodes spread across two or three Availability Zones, with replica shards in different AZs.
OpenSearch Dashboards
The built-in visualization UI (the successor to Kibana). Access can be controlled with IAM, Amazon Cognito or SAML.
Serverless option
OpenSearch Serverless removes domain sizing entirely. Capacity is measured in OpenSearch Compute Units (OCUs).

Storage Tiers

TierBacked byUse it for
HotData node storage (EBS or instance store)Recent, frequently written and queried data
UltraWarmAmazon S3 plus caching nodesOlder, read-only data that must stay interactive at a much lower cost
ColdAmazon S3Rarely queried data you attach on demand. The cheapest tier

Typical Ingestion Paths

  • Streaming logs or clickstream: Kinesis Data Streams or Amazon Data Firehose, with an OpenSearch destination.
  • Application logs: a CloudWatch Logs subscription that streams into OpenSearch.
  • Searchable DynamoDB data: DynamoDB Streams, then Lambda, then OpenSearch (or the managed zero-ETL integration).
  • Managed pipelines: OpenSearch Ingestion filters, transforms and routes data without servers.

For security, a domain can be deployed inside a VPC. Fine-grained access control adds index-level, document-level and field-level security.

Trigger phrases for OpenSearch
"Full-text search", "search by any attribute", "log analytics with dashboards", "near-real-time application monitoring", or "add search to data stored in DynamoDB" all point to OpenSearch. Querying logs in S3 occasionally with SQL is Athena. Metric dashboards for operations are CloudWatch or Managed Grafana.
