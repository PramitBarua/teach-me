AWS Security Hub and Amazon Detective

Lesson 14 of 23 · ~7 min

Source: What is Security Hub CSPM? · New Security Hub GA (Dec 2025) · What is Amazon Detective?

The Security module gave you a set of specialist detectors: GuardDuty (threats), Inspector (vulnerabilities), Macie (sensitive data in S3) and Config (resource compliance). Two questions remain. Where do you see all of their findings in one place? And once something looks wrong, how do you investigate what actually happened? Those are Security Hub and Detective.

Security Hub: One Pane, Plus Posture Checks

Naming update (December 2025)
The original service is now called AWS Security Hub CSPM (cloud security posture management). A new, broader AWS Security Hub reached general availability on 2 December 2025. It correlates signals from GuardDuty, Inspector, Macie and Security Hub CSPM into prioritized exposures. For the exam, think of it all as "Security Hub": the central aggregation and posture service.
Aggregate findings
Collects findings from GuardDuty, Inspector, Macie, Firewall Manager and other AWS services, plus third-party partner tools. They're normalized into a standard format (the AWS Security Finding Format, ASFF).
Posture checks against standards
Runs automated checks against security standards: AWS Foundational Security Best Practices, CIS AWS Foundations, PCI DSS and NIST. The checks are built on AWS Config rules, so Config must be enabled.
Multi-account and multi-Region
A delegated administrator account in AWS Organizations sees every member account. Cross-Region aggregation brings everything into one Region.
Response
Automation rules update findings. Findings go to EventBridge, which can trigger Lambda, Systems Manager Automation or a ticketing system for remediation.

Detective: Root-Cause Investigation

Detective automatically collects log data and builds a behavior graph showing how resources, IP addresses and identities interacted over time. It uses up to a year of history. Its sources are CloudTrail, VPC Flow Logs and GuardDuty findings (plus EKS audit logs). You don't need to set up those log pipelines yourself. Analysts pivot through visualizations to answer "what did this role do, from where, and what else did it touch?". Related findings are grouped together.

ServiceJob
GuardDutyDetects threats
Security HubAggregates findings and checks posture against standards
DetectiveInvestigates root cause after a finding
The three-word rule
Detect, aggregate, investigate. "A single dashboard of security findings across accounts, plus CIS or PCI compliance checks": Security Hub. "Analyze the root cause of a GuardDuty finding, visualize what happened, with no log pipelines to build": Detective. Detective doesn't detect new threats itself; that's GuardDuty's job.
