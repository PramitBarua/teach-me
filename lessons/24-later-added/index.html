Later Added: In-Scope Services the Course Skips

23 lessons · ~153 min total

Source: SAA-C03 in-scope AWS services · each lesson cites its AWS documentation

This module fills gaps. Each service below is on the official SAA-C03 in-scope services list but had no lesson in modules 05–23, or only a passing mention. Lessons are ordered roughly by how often each service appears in practice questions, so the highest-value topics come first. They're built from the current AWS documentation, so they include recent renames and retirements (QuickSight to Quick, Security Hub CSPM, Proton end of support, Data Pipeline and Discovery Service closing to new customers).

Exam scope
For most of these services the exam tests recognition: matching a scenario's trigger phrase to the right service, and rejecting a plausible look-alike. Each lesson ends with a "Keywords" or comparison callout for this reason. Drill those callouts, and revisit the quizzes a few days apart rather than all at once.
