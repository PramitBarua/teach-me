AWS Amplify and AWS Device Farm

Lesson 18 of 23 · ~5 min

Source: What is AWS Amplify Hosting? · What is AWS Device Farm?

The exam's "front-end web and mobile" category has two services. Both are aimed at application developers rather than infrastructure teams. You only need to recognize what each one does.

AWS Amplify: Full-Stack Web Apps, Git-Driven

Amplify Hosting
Connect a Git repository (GitHub, GitLab, Bitbucket, CodeCommit). Every push triggers a managed CI/CD build and deploys to a global CDN. It hosts static sites, single-page apps (React, Vue, Angular) and server-side rendered apps (Next.js, Nuxt).
Branch and preview environments
Each Git branch can become its own environment (dev, staging, prod). Pull requests can get temporary preview URLs.
Backends
Amplify (Gen 2) defines backend features in code, such as authentication with Cognito, data APIs with AppSync and DynamoDB, and storage with S3, and provisions them for you.

You'd get similar results from S3, CloudFront and CodePipeline, but you'd have to wire them up yourself. Amplify packages it all.

AWS Device Farm: Test on Real Devices

Device Farm is an app testing service. You run your Android, iOS and web apps on real phones and tablets (and desktop browsers) hosted by AWS, so you don't buy a device lab. You can:

  • run automated tests (Appium, Espresso, XCTest and others) in parallel across many devices, with logs, video and screenshots;
  • start a remote access session to tap and swipe a real device from your browser and reproduce a bug.
Keywords
"Front-end developers want to deploy a React or Next.js app from Git with CI/CD, hosting and a CDN, without managing infrastructure": Amplify Hosting. "Test a mobile app on many real devices without buying them": Device Farm.
