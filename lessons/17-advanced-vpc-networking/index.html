Advanced VPC Networking

5 lessons · ~37 min total

Source: Adrian Cantrill SAA-C03 · Amazon VPC User Guide

This module builds on VPC Basics with five topics that round out real-world and exam-tested VPC architecture: observability (flow logs), IPv6-specific outbound access, both types of private service access (gateway and interface endpoints), and connecting separate VPCs together (peering).

# Lesson Key idea
01VPC Flow LogsMetadata only, not real-time; VPC/subnet/ENI attachment levels; reading accept/reject pairs
02Egress-Only Internet GatewayThe IPv6 equivalent of NAT gateway's outbound-only behavior
03VPC Endpoints: Gateway EndpointsS3/DynamoDB only, prefix lists in route tables, automatically multi-AZ
04VPC Endpoints: Interface EndpointsPrivateLink, DNS-based, one endpoint per AZ needed, security groups apply
05VPC PeeringExactly two VPCs, never transitive, no overlapping CIDRs
Exam scope
The highest-yield facts here: gateway endpoints are automatically multi-AZ, interface endpoints are not (Lessons 03–04) — this distinction is tested directly and often; VPC peering is never transitive, and overlapping CIDRs block peering entirely (Lesson 05); and flow logs are metadata-only and not real-time (Lesson 01) — a frequent source of trick questions.
