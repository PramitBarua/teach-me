Security, Deployment and Operations

9 lessons · ~72 min total

Source: Adrian Cantrill SAA-C03 · AWS Security Incident Response Guide

This module covers AWS's dedicated security and compliance services: secrets and encryption key management (Secrets Manager, CloudHSM), perimeter defense (application-layer firewall theory, WAF, Shield), and the three "AWS finds problems for you" detective services that are easy to blur together — configuration drift (Config), sensitive data exposure (Macie), vulnerability scanning (Inspector), and account-wide threat detection (GuardDuty).

# Lesson Key idea
01AWS Secrets Manager"Secrets"/"rotation"/"RDS" keywords point here, not Parameter Store; Lambda-driven rotation kept in sync with the consuming product
02Application Layer (L7) FirewallsVendor-agnostic theory: L3/4 → +L5 session awareness → +L7 protocol awareness; HTTPS terminate-inspect-re-encrypt is what makes it possible
03Web Application Firewall (WAF)Web ACLs, rule groups/rules, WCU capacity, regular vs. rate-based rules (no "allow" for rate-based)
04AWS ShieldStandard is free and automatic; Advanced protections must be explicitly enabled per resource
05CloudHSMFIPS 140-3 Level 3 + industry-standard crypto APIs (PKCS#11/JCE/CNG) → CloudHSM; AWS-native integration → KMS
06AWS ConfigDetective, never preventive — records configuration history and compliance drift, doesn't block anything
07Amazon MacieS3-specific sensitive-data discovery; policy findings (posture got worse) vs. sensitive data findings (content matched)
08Amazon InspectorContinuous CVE/vulnerability scanning of EC2, ECR images, and Lambda — a fully rearchitected product since the course was recorded
09Amazon GuardDutyContinuous ML/threat-intel anomaly detection account-wide — not a scan you trigger, not a data-classification tool
Exam scope
Lesson 02's application-layer firewall theory is unusually dense with exam-flagged material in the source diagrams — the L3/4/5/7 capability build-up and the HTTPS terminate-inspect-re-encrypt mechanic are worth knowing cold. For the three "AWS finds problems for you" services that blur together, anchor on what each one actually scans: Config = configuration/compliance drift (detective only, never blocks a change), Macie = sensitive data inside S3, Inspector = CVE/vulnerability scanning of EC2/ECR/Lambda, GuardDuty = account-wide anomalous behavior via ML and threat intel. And remember Secrets Manager's tell: rotation, especially paired with RDS, is the keyword that beats Parameter Store every time (Lesson 01).
Two services here have changed architecture since the course was recorded
Amazon Inspector (Lesson 08) was completely rearchitected in December 2021 — the course describes the retired "Inspector Classic" (manual, duration-based assessments), while current Inspector runs continuous, automatic scanning via the SSM Agent. Inspector Classic itself reached end of support on May 20, 2026. Amazon GuardDuty (Lesson 09) has also added several protection plans (EKS, RDS, Lambda, Malware Protection, Runtime Monitoring, and an AI Protection plan for Bedrock/SageMaker) well beyond the four data sources the course describes. Both lessons teach the current architecture and flag the gap explicitly.
