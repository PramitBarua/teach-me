Containers & ECS

Containers & ECS

4 lessons · ~31 min total

Source: Adrian Cantrill SAA-C03 · Amazon ECS Developer Guide · Amazon ECR User Guide · Amazon EKS User Guide

This module covers running containers on AWS: how ECS orchestrates them across its two cluster modes, where container images live in ECR, and how EKS extends the same idea to managed Kubernetes. Together these cover the container-compute options a solutions architect needs to choose between for the exam.

# Lesson Key idea
01 ECS Concepts Container definitions, task definitions, tasks vs. services, and the task role vs. task execution role split
02 ECS Cluster Modes EC2 mode (you manage hosts, pay regardless of usage) vs. Fargate mode (serverless, pay per container)
03 Elastic Container Registry (ECR) Public vs. private registries, repositories/images/tags, basic vs. enhanced image scanning
04 Elastic Kubernetes Service (EKS) 101 AWS-managed control plane, self-managed/managed-node-group/Fargate node types, two-VPC architecture
Exam scope
The highest-yield details here are the task role vs. task execution role distinction (Lesson 01), knowing who pays for what and when across EC2 mode vs. Fargate mode (Lesson 02), and the public-read / gated-write asymmetry on ECR public registries (Lesson 03) — all easy to turn into "which option costs less / requires which permission" scenario questions.
