Network Storage & Data Lifecycle

Network Storage & Data Lifecycle

2 lessons · ~15 min total

Source: Adrian Cantrill SAA-C03 · Amazon EFS User Guide · AWS Backup Developer Guide

This module covers shared network storage and how AWS centralizes data protection across services. EFS gives EC2 fleets shared, mountable file storage; AWS Backup gives you one place to manage backup policy and retention across nearly every stateful AWS service. Both come up in scenario questions about stateless architecture and compliance-driven data retention.

# Lesson Key idea
01 EFS Architecture NFSv4 shared file storage for Linux; mount targets per-AZ; performance/throughput modes; Standard vs IA
02 AWS Backup Centralized backup plans, resources, vaults; Vault Lock WORM mode; cross-account/Region backup
Exam scope
The highest-yield details here are the mount-target-per-AZ requirement for EFS high availability, and the distinction between a plain (deletable) vault and a Vault Lock (WORM, undeletable after a 72-hour cool-off) — both are easy to test as "which option guarantees X" scenario questions.
