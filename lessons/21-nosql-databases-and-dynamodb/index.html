12 lessons · ~98 min total

Source: Adrian Cantrill SAA-C03 · Amazon DynamoDB Developer Guide

This module is built around DynamoDB — eight lessons covering its architecture, operations, and every major feature (indexes, streams, global tables, DAX, TTL) — followed by four adjacent data services that repeatedly get confused with each other and with DynamoDB on the exam: ad hoc S3 querying (Athena), in-memory caching (ElastiCache), and the analytical data warehouse (Redshift, across two lessons).

Exam scope
The single highest-yield DynamoDB distinction is Query needs a partition key value; Scan doesn't but reads (and bills for) the whole table (Lesson 02) — paired with eventually consistent reads cost half of strongly consistent ones (Lesson 03). For indexes: LSIs must be created with the base table; GSIs can be created anytime but are always eventually consistent (Lesson 04). For the four adjacent services, anchor on what each one is actually for: DAX = DynamoDB-specific caching (not for strongly-consistent-read workloads), Athena = ad hoc, serverless querying of data already in S3, ElastiCache = general-purpose in-memory caching that requires application changes, Redshift = a provisioned, columnar OLAP data warehouse for petabyte-scale analytics — not for ad hoc queries, that's Athena's job.
Several services here have gained real capabilities since the course was recorded
DynamoDB now offers a Standard-IA table class (Lesson 01) and Global Tables terminology has shifted from "multi-master" to "multi-active" with broader replica feature parity (Lesson 06). Athena can now perform real INSERT/UPDATE/DELETE against Apache Iceberg tables, not just read-only S3 querying (Lesson 09). ElastiCache Serverless removes the need to size or manage cache nodes at all (Lesson 10). Most significantly, Amazon Redshift Multi-AZ has been generally available for RA3 clusters since November 2023 — directly qualifying the "Redshift is single-AZ only" architecture taught as the foundational default in Lesson 11 (independently verified, not just taken from a single source).
