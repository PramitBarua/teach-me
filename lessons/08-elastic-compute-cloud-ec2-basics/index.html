EC2 Basics

Elastic Compute Cloud (EC2) Basics

21 lessons · ~3 hours total

Source: Adrian Cantrill SAA-C03 · AWS EC2 User Guide

This module covers EC2 from the virtualization fundamentals underneath it through to the day-to-day decisions a solutions architect makes: which storage type to attach, how to size and purchase capacity, and how to keep instances resilient. EC2 is the single most heavily-tested service on the SAA-C03 exam, and the concepts here — EBS volume types, instance store vs. EBS, purchase options, and IMDSv2 — recur constantly across almost every other domain in the course.

Exam scope
The highest-yield topics in this module are EBS volume type selection (matching gp3/io2/st1/sc1 to a workload's IOPS and throughput needs), the instance store vs. EBS persistence trade-off, EC2 purchase options (On-Demand vs. Reserved vs. Spot vs. Savings Plans, and when each fits a scenario), and IMDSv2 as the standard hardening answer against SSRF-driven credential theft.
