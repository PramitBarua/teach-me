Hybrid Environments and Migration

16 lessons · ~126 min total

Source: Adrian Cantrill SAA-C03 · AWS Direct Connect User Guide

This module covers connecting AWS to the outside world: on-premises networks, existing directories, and bulk data. It splits into three arcs — private connectivity (BGP → IPSec → Site-to-Site VPN → Direct Connect ×3 → Transit Gateway), storage and data movement (Storage Gateway's three modes, the Snow family, DataSync), and hybrid identity and file systems (Directory Service, FSx ×2, Transfer Family).

Exam scope
Storage Gateway mode selection is the single highest-yield topic here — the keyword heuristic is "volume" → Volume Gateway, "tape" → Tape Gateway (VTL), "file"/NFS/SMB → File Gateway (Lessons 08–10), and within Volume Gateway, backup/DR language → stored mode, capacity/extension language → cached mode. Direct Connect resilience (Lesson 05) and the VGW/CGW partial-vs-full-HA distinction (Lesson 03) both show up as "spot the remaining single point of failure" questions. Transit Gateway's transitive routing (Lesson 07) is what separates it from VPC peering. And for hybrid identity, remember the decision order in Lesson 12: Simple AD by default, Managed Microsoft AD for real-AD/trust needs, AD Connector when directory data can never touch AWS.
This module has more stale-vs-current corrections than most
Several products in this module have moved meaningfully since the course was recorded — most notably, the entire Snow family closed to new customers in November 2025 (Lesson 11), and Simple AD closes to new customers on July 30, 2026 (Lesson 12) — a date worth knowing if directory decisions are on the table soon. Each affected lesson flags its own correction inline; the exam still tests the course's architectural reasoning even where the underlying product availability has changed.
