      Question 76

      As part of budget planning, management wants a report of AWS billed items listed by user. The data will be used to create department budgets. A solutions architect needs to determine the most efficient way to obtain this report information. Which solution meets these requirements?

      • A. Run a query with Amazon Athena to generate the report.
      • B. Create a report in Cost Explorer and download the report.
      • C. Access the bill details from the billing dashboard and download the bill.
      • D. Modify a cost budget in AWS Budgets to alert with Amazon Simple Email Service (Amazon SES).

      Domain: Design Cost-Optimized Architectures

      Correct answer: B

      • A. Wrong — Athena queries data already sitting in a source like S3; billing data isn't queryable this way without first setting up a Cost and Usage Report pipeline, which is significantly more setup than a built-in reporting tool already provides.
      • B. Correct — Cost Explorer can group and filter cost data by user (via cost allocation tags or linked account/user dimensions) and lets you build and download a report directly — the most efficient built-in path to this exact report.
      • C. Wrong — the billing dashboard shows overall bill details and summaries; it doesn't break billed items down by individual user the way Cost Explorer's grouping does.
      • D. Wrong — AWS Budgets sends alerts when spending crosses a threshold; it's a monitoring/alerting tool, not a per-user billed-items reporting tool.

      Question 77

      A company hosts its web application on AWS using seven Amazon EC2 instances. The company requires that the IP addresses of all healthy EC2 instances be returned in response to DNS queries. Which policy should be used to meet this requirement?

      • A. Simple routing policy
      • B. Latency routing policy
      • C. Multivalue routing policy
      • D. Geolocation routing policy

      Domain: Design Resilient Architectures

      Correct answer: C

      • A. Wrong — simple routing typically returns a single record (or all values for one record with no health-check filtering), not specifically "all healthy" instances as a health-aware set.
      • B. Wrong — latency routing picks the single Region/resource with the lowest latency to the user; it doesn't return multiple healthy IP addresses in one response.
      • C. Correct — multivalue answer routing returns up to eight healthy records selected at random in response to each DNS query (all seven here fit within that limit), and Route 53 excludes any record whose associated health check reports unhealthy — exactly matching "IP addresses of all healthy EC2 instances."
      • D. Wrong — geolocation routing selects a record based on the geographic location of the query, not the health of every instance, and doesn't return multiple IP addresses per response.

      Question 78

      A company runs analytics software on Amazon EC2 instances. The software accepts job requests from users to process data that has been uploaded to Amazon S3. Users report that some submitted data is not being processed. Amazon CloudWatch reveals that the EC2 instances have a consistent CPU utilization at or near 100%. The company wants to improve system performance and scale the system based on user load. What should a solutions architect do to meet these requirements?

      • A. Create a copy of the instance. Place all instances behind an Application Load Balancer.
      • B. Create an S3 VPC endpoint for Amazon S3. Update the software to reference the endpoint.
      • C. Stop the EC2 instances. Modify the instance type to one with a more powerful CPU and more memory. Restart the instances.
      • D. Route incoming requests to Amazon Simple Queue Service (Amazon SQS). Configure an EC2 Auto Scaling group based on queue size. Update the software to read from the queue.

      Domain: Design Resilient Architectures

      Correct answer: D

      • A. Wrong — an ALB distributes incoming web-style requests across instances, but this analytics job-processing workload isn't a request/response web tier being load balanced, and a fixed second copy doesn't scale based on load.
      • B. Wrong — an S3 VPC endpoint improves network path/cost to S3; it does nothing about the CPU being pegged at 100% or about scaling processing capacity with demand.
      • C. Wrong — resizing to a bigger instance type is a one-time manual vertical scale that still has a ceiling and doesn't scale automatically with variable user load.
      • D. Correct — decoupling with SQS absorbs job requests durably even when instances are saturated, and scaling an Auto Scaling group on queue size adds processing capacity automatically as load grows — directly fixing both the dropped-job problem and the "scale based on user load" requirement.

      Question 79

      A solutions architect needs to design a highly available application consisting of web, application, and database tiers. HTTPS content delivery should be as close to the edge as possible, with the least delivery time. Which solution meets these requirements and is MOST secure?

      • A. Configure a public Application Load Balancer (ALB) with multiple redundant Amazon EC2 instances in public subnets. Configure Amazon CloudFront to deliver HTTPS content using the public ALB as the origin.
      • B. Configure a public Application Load Balancer with multiple redundant Amazon EC2 instances in private subnets. Configure Amazon CloudFront to deliver HTTPS content using the EC2 instances as the origin.
      • C. Configure a public Application Load Balancer (ALB) with multiple redundant Amazon EC2 instances in private subnets. Configure Amazon CloudFront to deliver HTTPS content using the public ALB as the origin.
      • D. Configure a public Application Load Balancer with multiple redundant Amazon EC2 instances in public subnets. Configure Amazon CloudFront to deliver HTTPS content using the EC2 instances as the origin.

      Domain: Design Secure Architectures

      Correct answer: C

      • A. Wrong — putting the EC2 instances in public subnets exposes them directly to the internet, which is less secure than keeping them private behind the ALB.
      • B. Wrong — using the EC2 instances themselves (rather than the ALB) as the CloudFront origin bypasses the load balancer entirely and exposes the instances directly, undermining both the "highly available" load-balanced design and security.
      • C. Correct — EC2 instances stay private (never directly internet-reachable, only through the ALB), the public ALB handles load balancing and health checks, and CloudFront caches HTTPS content at the edge using the ALB as origin — the most secure combination that also delivers content as close to users as possible.
      • D. Wrong — this combines the least secure choices from both dimensions: EC2 instances directly exposed in public subnets, and CloudFront pointed at the instances directly instead of through the ALB.

      Question 80

      A company has a multi-tier application that runs six front-end web servers in an Amazon EC2 Auto Scaling group in a single Availability Zone behind an Application Load Balancer (ALB). A solutions architect needs to modify the infrastructure to be highly available without modifying the application. Which architecture should the solutions architect choose that provides high availability?

      • A. Create an Auto Scaling group that uses three instances across each of two Regions.
      • B. Modify the Auto Scaling group to use three instances across each of two Availability Zones.
      • C. Create an Auto Scaling template that can be used to quickly create more instances in another Region.
      • D. Change the ALB in front of the Amazon EC2 instances in a round-robin configuration to balance traffic to the web tier.

      Domain: Design Resilient Architectures

      Correct answer: B

      • A. Wrong — spanning multiple Regions introduces cross-Region networking/latency/data-replication complexity far beyond what's needed for basic high availability, and isn't a simple "without modifying the application" change.
      • B. Correct — spreading the same six instances across two Availability Zones within the existing Region gives high availability against a single AZ failure, using only an Auto Scaling group configuration change with no application code changes.
      • C. Wrong — a template that "can be used to quickly create more instances" is a manual, reactive process, not the automatic, always-on high availability the requirement calls for.
      • D. Wrong — ALBs already route in a round-robin-like fashion by default across registered healthy targets; explicitly configuring "round-robin" doesn't address the underlying single-AZ availability risk at all.

      Question 81

      A company's website provides users with downloadable historical performance reports. The website needs a solution that will scale to meet the company's website demands globally. The solution should be cost-effective, limit the provisioning of infrastructure resources, and provide the fastest possible response time. Which combination should a solutions architect recommend to meet these requirements?

      • A. Amazon CloudFront and Amazon S3
      • B. AWS Lambda and Amazon DynamoDB
      • C. Application Load Balancer with Amazon EC2 Auto Scaling
      • D. Amazon Route 53 with internal Application Load Balancers

      Domain: Design Cost-Optimized Architectures

      Correct answer: A

      • A. Correct — the reports are simple static downloadable files, so S3 provides durable, unlimited storage with zero servers to provision, and CloudFront caches them at edge locations worldwide for the fastest response time — the lowest-cost, least-infrastructure combination for this exact need.
      • B. Wrong — Lambda and DynamoDB are suited to dynamic application logic and structured data queries, not simply serving static downloadable report files, and add unnecessary complexity for this use case.
      • C. Wrong — an ALB with EC2 Auto Scaling still requires provisioning and running compute instances, conflicting with "limit the provisioning of infrastructure resources," and doesn't inherently provide global edge caching for fastest response time.
      • D. Wrong — internal Application Load Balancers aren't internet-facing at all, so they can't serve public website users, and this combination still requires provisioning compute behind the ALBs.

      Question 82

      A company uses 50 TB of data for reporting. The company wants to move this data from on premises to AWS. A custom application in the company's data center runs a weekly data transformation job. The company plans to pause the application until the data transfer is complete and needs to begin the transfer process as soon as possible. The data center does not have any available network bandwidth for additional workloads. A solutions architect must transfer the data and must configure the transformation job to continue to run in the AWS Cloud. Which solution will meet these requirements with the LEAST operational overhead?

      • A. Use AWS DataSync to move the data. Create a custom transformation job by using AWS Glue.
      • B. Order an AWS Snowcone device to move the data. Deploy the transformation application to the device.
      • C. Order an AWS Snowball Edge Storage Optimized device. Copy the data to the device. Create a custom transformation job by using AWS Glue.
      • D. Order an AWS Snowball Edge Storage Optimized device that includes Amazon EC2 compute. Copy the data to the device. Create a new EC2 instance on AWS to run the transformation application.

      Domain: Design Resilient Architectures

      Correct answer: C

      • A. Wrong — DataSync transfers data over the network, but the data center has no available network bandwidth for this workload, ruling out a network-based transfer entirely.
      • B. Wrong — a single Snowcone device's capacity (a few terabytes) is far too small to efficiently move 50 TB, requiring many device cycles.
      • C. Correct — a Snowball Edge Storage Optimized device moves the 50 TB offline (no network bandwidth needed), and AWS Glue provides a fully managed, serverless place to recreate the transformation job in AWS — no new compute infrastructure to operate.
      • D. Wrong — adding EC2 compute to the Snowball device and then standing up a new EC2 instance to run the transformation application afterward means the company must build and operate that instance/application itself — more operational overhead than using managed Glue.

      Question 83

      A company is preparing a new data platform that will ingest real-time streaming data from multiple sources. The company needs to transform the data before writing the data to Amazon S3. The company needs the ability to use SQL to query the transformed data. Which solutions will meet these requirements? (Choose two.)

      • A. Use Amazon Kinesis Data Streams to stream the data. Use Amazon Kinesis Data Analytics to transform the data. Use Amazon Kinesis Data Firehose to write the data to Amazon S3. Use Amazon Athena to query the transformed data from Amazon S3.
      • B. Use Amazon Managed Streaming for Apache Kafka (Amazon MSK) to stream the data. Use AWS Glue to transform the data and to write the data to Amazon S3. Use Amazon Athena to query the transformed data from Amazon S3.
      • C. Use AWS Database Migration Service (AWS DMS) to ingest the data. Use Amazon EMR to transform the data and to write the data to Amazon S3. Use Amazon Athena to query the transformed data from Amazon S3.
      • D. Use Amazon Managed Streaming for Apache Kafka (Amazon MSK) to stream the data. Use Amazon Kinesis Data Analytics to transform the data and to write the data to Amazon S3. Use the Amazon RDS query editor to query the transformed data from Amazon S3.
      • E. Use Amazon Kinesis Data Streams to stream the data. Use AWS Glue to transform the data. Use Amazon Kinesis Data Firehose to write the data to Amazon S3. Use the Amazon RDS query editor to query the transformed data from Amazon S3.

      Domain: Design High-Performing Architectures

      Correct answer: A, B

      • A. Correct — Kinesis Data Streams ingests the real-time streams, Kinesis Data Analytics runs SQL-based transformation on that streaming data, Kinesis Data Firehose delivers the results to S3, and Athena provides SQL querying directly against the S3 data.
      • B. Correct — Amazon MSK ingests real-time streams via managed Kafka, AWS Glue provides serverless ETL to transform and write to S3, and Athena again provides the required SQL querying against S3.
      • C. Wrong — AWS DMS is built for database migration/replication, not for ingesting real-time streaming data from multiple general sources.
      • D. Wrong — the Amazon RDS query editor runs SQL against data living inside an RDS database, not against files sitting in S3, so it can't query the transformed S3 data as required.
      • E. Wrong — same problem as D: the RDS query editor doesn't query data stored in S3.

      Question 84

      A company needs to review its AWS Cloud deployment to ensure that its Amazon S3 buckets do not have unauthorized configuration changes. What should a solutions architect do to accomplish this goal?

      • A. Turn on AWS Config with the appropriate rules.
      • B. Turn on AWS Trusted Advisor with the appropriate checks.
      • C. Turn on Amazon Inspector with the appropriate assessment template.
      • D. Turn on Amazon S3 server access logging. Configure Amazon EventBridge (Amazon Cloud Watch Events).

      Domain: Design Secure Architectures

      Correct answer: A

      • A. Correct — AWS Config continuously records resource configuration state and, with rules like S3 bucket public-access or encryption checks, evaluates every configuration change against the desired state and flags/records unauthorized changes.
      • B. Wrong — Trusted Advisor runs periodic best-practice checks (cost, security, performance); it isn't built for continuous configuration-change tracking and compliance evaluation the way Config is.
      • C. Wrong — Amazon Inspector performs vulnerability assessments of EC2 instances and container images; it has no role in monitoring S3 bucket configuration changes.
      • D. Wrong — S3 server access logging records requests made to the bucket (who accessed what), not configuration changes to the bucket itself, so it doesn't directly detect unauthorized configuration changes the way Config rules do.

      Question 85

      A company is designing a cloud communications platform that is driven by APIs. The application is hosted on Amazon EC2 instances behind a Network Load Balancer (NLB). The company uses Amazon API Gateway to provide external users with access to the application through APIs. The company wants to protect the platform against web exploits like SQL injection and also wants to detect and mitigate large, sophisticated DDoS attacks. Which combination of solutions provides the MOST protection? (Choose two.)

      • A. Use AWS WAF to protect the NLB.
      • B. Use AWS Shield Advanced with the NLB.
      • C. Use AWS WAF to protect Amazon API Gateway.
      • D. Use Amazon GuardDuty with AWS Shield Standard.
      • E. Use AWS Shield Standard with Amazon API Gateway.

      Domain: Design Secure Architectures

      Correct answer: B, C

      • A. Wrong — AWS WAF only attaches to CloudFront, ALB, API Gateway, and a few other Layer 7 resource types; it does not support Network Load Balancers, so this configuration isn't actually possible.
      • B. Correct — Shield Advanced does support Network Load Balancers as a protected resource, providing enhanced DDoS detection and mitigation for large, sophisticated attacks against the NLB.
      • C. Correct — AWS WAF attaches directly to API Gateway to inspect and block web exploits like SQL injection before requests reach the backend.
      • D. Wrong — GuardDuty is a threat-detection service that produces findings; it doesn't block SQL injection or actively mitigate DDoS traffic, and Shield Standard alone provides only baseline, automatic protection without the advanced detection/response the requirement calls for.
      • E. Wrong — Shield Standard is already included automatically for all AWS customers and provides only basic protection; it doesn't address the SQL-injection requirement at all and isn't sufficient for "large, sophisticated" attacks the way Shield Advanced is.

      Question 86

      A company has a serverless website with millions of objects in an Amazon S3 bucket. The company uses the S3 bucket as the origin for an Amazon CloudFront distribution. The company did not set encryption on the S3 bucket before the objects were loaded. A solutions architect needs to enable encryption for all existing objects and for all objects that are added to the S3 bucket in the future. Which solution will meet these requirements with the LEAST amount of effort?

      • A. Create a new S3 bucket. Turn on the default encryption settings for the new S3 bucket. Download all existing objects to temporary local storage. Upload the objects to the new S3 bucket.
      • B. Turn on the default encryption settings for the S3 bucket. Use the S3 Inventory feature to create a .csv file that lists the unencrypted objects. Run an S3 Batch Operations job that uses the copy command to encrypt those objects.
      • C. Create a new encryption key by using AWS Key Management Service (AWS KMS). Change the settings on the S3 bucket to use server-side encryption with AWS KMS managed encryption keys (SSE-KMS). Turn on versioning for the S3 bucket.
      • D. Navigate to Amazon S3 in the AWS Management Console. Browse the S3 bucket's objects. Sort by the encryption field. Select each unencrypted object. Use the Modify button to apply default encryption settings to every unencrypted object in the S3 bucket.

      Domain: Design Secure Architectures

      Correct answer: B

      • A. Wrong — manually downloading and re-uploading millions of objects through temporary local storage is extremely high effort and slow at this scale.
      • B. Correct — default encryption covers all future objects automatically, S3 Inventory efficiently lists exactly which existing objects are unencrypted, and a single S3 Batch Operations copy job encrypts all of them in bulk — the least-effort way to handle millions of existing objects.
      • C. Wrong — changing the bucket's default encryption setting (to SSE-KMS or otherwise) only affects newly uploaded objects; it does not retroactively encrypt the millions of objects that already exist in the bucket, and versioning is unrelated to this requirement.
      • D. Wrong — manually selecting and modifying encryption settings object-by-object (or even via bulk console selection) across millions of objects is impractical and far higher effort than a single Batch Operations job.

      Question 87

      A company runs a web-based portal that provides users with global breaking news, local alerts, and weather updates. The portal delivers each user a personalized view by using a mixture of static and dynamic content. Content is served over HTTPS through an API server running on an Amazon EC2 instance behind an Application Load Balancer (ALB). The company wants the portal to provide this content to its users across the world as quickly as possible. How should a solutions architect design the application to ensure the LEAST amount of latency for all users?

      • A. Deploy the application stack in a single AWS Region. Use Amazon CloudFront to serve all static and dynamic content by specifying the ALB as an origin.
      • B. Deploy the application stack in two AWS Regions. Use an Amazon Route 53 latency routing policy to serve all content from the ALB in the closest Region.
      • C. Deploy the application stack in a single AWS Region. Use Amazon CloudFront to serve the static content. Serve the dynamic content directly from the ALB.
      • D. Deploy the application stack in two AWS Regions. Use an Amazon Route 53 geolocation routing policy to serve all content from the ALB in the closest Region.

      Domain: Design High-Performing Architectures

      Correct answer: A

      • A. Correct — CloudFront's globally distributed edge network gets content, static and dynamic, physically closer to every user than a single Region ever could, and connections traverse AWS's private backbone from the edge to the ALB origin, minimizing latency without any multi-Region deployment complexity.
      • B. Wrong — even with latency-based routing to the closer of two Regions, users still connect directly to a distant ALB over the public internet with no edge caching, which is slower than a global CloudFront edge network reaching a single origin.
      • C. Wrong — serving dynamic content "directly from the ALB" skips CloudFront's edge network and AWS backbone benefits for that portion of traffic, adding latency for users far from the single Region compared to routing all traffic through CloudFront.
      • D. Wrong — geolocation routing selects a Region based on the user's geographic location, not necessarily the lowest-latency path, and like B still lacks edge caching for either content type.

      Question 88

      A solutions architect is designing a VPC with public and private subnets. The VPC and subnets use IPv4 CIDR blocks. There is one public subnet and one private subnet in each of three Availability Zones (AZs) for high availability. An internet gateway is used to provide internet access for the public subnets. The private subnets require access to the internet to allow Amazon EC2 instances to download software updates. What should the solutions architect do to enable Internet access for the private subnets?

      • A. Create three NAT gateways, one for each public subnet in each AZ. Create a private route table for each AZ that forwards non-VPC traffic to the NAT gateway in its AZ.
      • B. Create three NAT instances, one for each private subnet in each AZ. Create a private route table for each AZ that forwards non-VPC traffic to the NAT instance in its AZ.
      • C. Create a second internet gateway on one of the private subnets. Update the route table for the private subnets that forward non-VPC traffic to the private internet gateway.
      • D. Create an egress-only internet gateway on one of the public subnets. Update the route table for the private subnets that forward non-VPC traffic to the egress-only Internet gateway.

      Domain: Design Resilient Architectures

      Correct answer: A

      • A. Correct — a NAT gateway per AZ (placed in that AZ's public subnet) avoids a cross-AZ single point of failure, and a separate private route table per AZ pointing to its own AZ's NAT gateway keeps each AZ's outbound path independent, matching the three-AZ high-availability design.
      • B. Wrong — self-managed NAT instances require you to patch, scale, and manage failover yourself, unlike the fully managed NAT gateway; NAT instances also sit in a public subnet, not the private subnet as described here.
      • C. Wrong — a VPC can only have one internet gateway attached, and an internet gateway grants direct inbound+outbound internet reachability, which isn't appropriate for private subnets or how "private" access is meant to work.
      • D. Wrong — an egress-only internet gateway is specifically for IPv6 traffic; this VPC uses IPv4 CIDR blocks, so this construct doesn't apply here at all.

      Question 89

      A company has an application that runs on Amazon EC2 instances and uses an Amazon Aurora database. The EC2 instances connect to the database by using user names and passwords that are stored locally in a file. The company wants to minimize the operational overhead of credential management. What should a solutions architect do to accomplish this goal?

      • A. Use AWS Secrets Manager. Turn on automatic rotation.
      • B. Use AWS Systems Manager Parameter Store. Turn on automatic rotation.
      • C. Create an Amazon S3 bucket to store objects that are encrypted with an AWS Key Management Service (AWS KMS) encryption key. Migrate the credential file to the S3 bucket. Point the application to the S3 bucket.
      • D. Create an encrypted Amazon Elastic Block Store (Amazon EBS) volume for each EC2 instance. Attach the new EBS volume to each EC2 instance. Migrate the credential file to the new EBS volume. Point the application to the new EBS volume.

      Domain: Design Secure Architectures

      Correct answer: A

      • A. Correct — Secrets Manager natively integrates with Aurora and provides built-in scheduled automatic rotation with no custom code, directly minimizing the operational overhead of managing database credentials.
      • B. Wrong — Parameter Store secure strings can hold secrets but don't have Secrets Manager's built-in automatic rotation workflow for Aurora; achieving rotation here would require custom automation, adding overhead.
      • C. Wrong — moving the plain credential file to an encrypted S3 bucket still requires manually managing and rotating those credentials; it doesn't reduce operational overhead, just relocates the same problem.
      • D. Wrong — moving the credential file to an encrypted EBS volume has the same issue as C: the credentials still require manual management and rotation, with no automated lifecycle.

      Question 90

      A solutions architect is using Amazon S3 to design the storage architecture of a new digital media application. The media files must be resilient to the loss of an Availability Zone. Some files are accessed frequently while other files are rarely accessed in an unpredictable pattern. The solutions architect must minimize the costs of storing and retrieving the media files. Which storage option meets these requirements?

      • A. S3 Standard
      • B. S3 Intelligent-Tiering
      • C. S3 Standard-Infrequent Access (S3 Standard-IA)
      • D. S3 One Zone-Infrequent Access (S3 One Zone-IA)

      Domain: Design Cost-Optimized Architectures

      Correct answer: B

      • A. Wrong — S3 Standard is resilient to AZ loss, but it doesn't optimize cost for files that are rarely accessed, missing the cost-minimization requirement for that portion of the data.
      • B. Correct — Intelligent-Tiering is resilient to AZ loss (same multi-AZ design as S3 Standard) and automatically moves objects between frequent- and infrequent-access tiers based on actual, unpredictable access patterns with no retrieval fees — directly minimizing cost without manual tier management.
      • C. Wrong — Standard-IA is resilient to AZ loss, but it charges a retrieval fee every time a "frequently accessed" file is read, which isn't cost-optimal given some files are accessed often.
      • D. Wrong — One Zone-IA stores data in a single Availability Zone by design, so it is not resilient to the loss of an Availability Zone, directly violating the requirement.

      Question 91

      A company has an ecommerce checkout workflow that writes an order to a database and calls a service to process the payment. Users are experiencing timeouts during the checkout process. When users resubmit the checkout form, multiple unique orders are created for the same desired transaction. How should a solutions architect refactor this workflow to prevent the creation of multiple orders?

      • A. Configure the web application to send an order message to Amazon Kinesis Data Firehose. Set the payment service to retrieve the message from Kinesis Data Firehose and process the order.
      • B. Create a rule in AWS CloudTrail to invoke an AWS Lambda function based on the logged application path request. Use Lambda to query the database, call the payment service, and pass in the order information.
      • C. Store the order in the database. Send a message that includes the order number to Amazon Simple Notification Service (Amazon SNS). Set the payment service to poll Amazon SNS, retrieve the message, and process the order.
      • D. Store the order in the database. Send a message that includes the order number to an Amazon Simple Queue Service (Amazon SQS) FIFO queue. Set the payment service to retrieve the message and process the order. Delete the message from the queue.

      Domain: Design Resilient Architectures

      Correct answer: D

      • A. Wrong — Kinesis Data Firehose is a one-way delivery pipe to a destination (like S3); it isn't designed for a payment service to retrieve and process individual order messages with duplicate protection.
      • B. Wrong — CloudTrail logs management/API events with delay; triggering Lambda off "logged application path requests" is an indirect, unreliable, and roundabout way to process checkouts in near real time, and doesn't inherently prevent duplicate processing.
      • C. Wrong — SNS is a push-based pub/sub service without a native poll-and-retrieve consumer model or built-in duplicate suppression; it doesn't prevent the same resubmitted order from being processed twice.
      • D. Correct — an SQS FIFO queue provides exactly-once processing semantics (via deduplication), so even if the checkout form is resubmitted, the payment service processes the order idempotently instead of creating multiple orders.

      Question 92

      A research laboratory needs to process approximately 8 TB of data. The laboratory requires sub-millisecond latencies and a minimum throughput of 6 GBps for the storage subsystem. Hundreds of Amazon EC2 instances that run Amazon Linux will distribute and process the data. Which solution will meet the performance requirements?

      • A. Create an Amazon FSx for NetApp ONTAP file system. Set each volume's tiering policy to ALL. Import the raw data into the file system. Mount the file system on the EC2 instances.
      • B. Create an Amazon S3 bucket to store the raw data. Create an Amazon FSx for Lustre file system that uses persistent SSD storage. Select the option to import data from and export data to Amazon S3. Mount the file system on the EC2 instances.
      • C. Create an Amazon S3 bucket to store the raw data. Create an Amazon FSx for Lustre file system that uses persistent HDD storage. Select the option to import data from and export data to Amazon S3. Mount the file system on the EC2 instances.
      • D. Create an Amazon FSx for NetApp ONTAP file system. Set each volume's tiering policy to NONE. Import the raw data into the file system. Mount the file system on the EC2 instances.

      Domain: Design High-Performing Architectures

      Correct answer: B

      • A. Wrong — a tiering policy of ALL moves the data to the slower capacity pool tier, which directly conflicts with the sub-millisecond latency requirement.
      • B. Correct — FSx for Lustre is purpose-built for exactly this HPC profile: sub-millisecond latencies and throughput that scales into the hundreds of GBps, and persistent SSD storage sustains that performance; the S3 import/export linkage lets the same 8 TB dataset be processed by hundreds of Linux EC2 instances and results written back to S3.
      • C. Wrong — persistent HDD storage has meaningfully lower throughput/IOPS ceilings than SSD, making it a weaker fit for the 6 GBps and sub-millisecond latency targets than option B.
      • D. Wrong — a NetApp ONTAP file system is a general-purpose, multi-protocol NAS; even with tiering disabled to keep everything on SSD, it isn't the purpose-built HPC parallel file system that FSx for Lustre is for this scale of throughput and latency.

      Question 93

      A company is building a web-based application running on Amazon EC2 instances in multiple Availability Zones. The web application will provide access to a repository of text documents totaling about 900 TB in size. The company anticipates that the web application will experience periods of high demand. A solutions architect must ensure that the storage component for the text documents can scale to meet the demand of the application at all times. The company is concerned about the overall cost of the solution. Which storage solution meets these requirements MOST cost-effectively?

      • A. Amazon Elastic Block Store (Amazon EBS)
      • B. Amazon Elastic File System (Amazon EFS)
      • C. Amazon OpenSearch Service (Amazon Elasticsearch Service)
      • D. Amazon S3

      Domain: Design Cost-Optimized Architectures

      Correct answer: D

      • A. Wrong — an EBS volume is tied to a single instance and Availability Zone with a fixed provisioned size; it doesn't natively scale to serve shared content across multiple AZs, and is generally more expensive per GB at 900 TB scale than S3.
      • B. Wrong — EFS can scale and be shared across AZs, but its per-GB cost is higher than S3's at hundreds of terabytes of scale, making it less cost-effective for this use case.
      • C. Wrong — OpenSearch Service is built for search/analytics workloads over indexed data, not for storing and serving a 900 TB repository of raw text document files at the lowest cost.
      • D. Correct — S3 scales essentially without limit to absorb any demand spike, requires no capacity provisioning ahead of time, and offers the lowest cost per GB of these options at this scale — the most cost-effective fit for a large, elastically-accessed document repository.

      Question 97

      Question 100

      A company has an application that places hundreds of .csv files into an Amazon S3 bucket every hour. The files are 1 GB in size.
