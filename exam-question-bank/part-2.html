      Question 26

      A company is migrating its on-premises PostgreSQL database to Amazon Aurora PostgreSQL. The on-premises database must remain online and accessible during the migration. The Aurora database must remain synchronized with the on-premises database. Which combination of actions must a solutions architect take to meet these requirements? (Choose two.)

      • A. Create an ongoing replication task.
      • B. Create a database backup of the on-premises database.
      • C. Create an AWS Database Migration Service (AWS DMS) replication server.
      • D. Convert the database schema by using the AWS Schema Conversion Tool (AWS SCT).
      • E. Create an Amazon EventBridge (Amazon CloudWatch Events) rule to monitor the database synchronization.

      Domain: Design Resilient Architectures

      Correct answer: A, C

      • A. Correct — an ongoing (CDC) replication task is what keeps the Aurora target continuously synchronized with an on-premises source database that must stay online and keep serving traffic throughout the migration.
      • B. Wrong — a database backup is a point-in-time copy; it doesn't keep the target continuously synchronized with an on-premises source that keeps changing while it stays online.
      • C. Correct — an AWS DMS replication instance (server) is the compute resource DMS requires to run any migration/replication task, full load or ongoing CDC — required infrastructure for this migration.
      • D. Wrong — AWS SCT converts schemas between different database engines; source and target here are both PostgreSQL (homogeneous), so no schema conversion tool is required.
      • E. Wrong — an EventBridge rule to monitor synchronization is observability after the fact; it doesn't perform or establish the replication itself.

      Question 27

      A company runs a stateless web application in production on a group of Amazon EC2 On-Demand Instances behind an Application Load Balancer. The application experiences heavy usage during an 8-hour period each business day. Application usage is moderate and steady overnight. Application usage is low during weekends. The company wants to minimize its EC2 costs without affecting the availability of the application. Which solution will meet these requirements?

      • A. Use Spot Instances for the entire workload.
      • B. Use Reserved Instances for the baseline level of usage. Use Spot instances for any additional capacity that the application needs.
      • C. Use On-Demand Instances for the baseline level of usage. Use Spot Instances for any additional capacity that the application needs.
      • D. Use Dedicated Instances for the baseline level of usage. Use On-Demand Instances for any additional capacity that the application needs.

      Domain: Design Cost-Optimized Architectures

      Correct answer: B

      • A. Wrong — running the entire workload, including the always-on baseline, on Spot Instances risks reclamation at any time, which threatens the "without affecting availability" requirement.
      • B. Correct — Reserved Instances give guaranteed, discounted capacity for the steady always-on baseline (moderate overnight, low weekend usage still needs a floor of capacity), while cheap Spot Instances cost-effectively cover the extra 8-hour daily peak for this stateless, interruption-tolerant application.
      • C. Wrong — On-Demand pricing for a known, steady baseline costs more than committing to Reserved Instances for that same guaranteed usage.
      • D. Wrong — Dedicated Instances add a dedicated-hardware premium with no stated need for it, and On-Demand for the bursty additional capacity costs more than Spot for this interruption-tolerant, stateless workload.

      Question 28

      A company is running an online transaction processing (OLTP) workload on AWS. This workload uses an unencrypted Amazon RDS DB instance in a Multi-AZ deployment. Daily database snapshots are taken from this instance. What should a solutions architect do to ensure the database and snapshots are always encrypted moving forward?

      • A. Encrypt a copy of the latest DB snapshot. Replace existing DB instance by restoring the encrypted snapshot.
      • B. Create a new encrypted Amazon Elastic Block Store (Amazon EBS) volume and copy the snapshots to it. Enable encryption on the DB instance.
      • C. Copy the snapshots and enable encryption using AWS Key Management Service (AWS KMS). Restore encrypted snapshot to an existing DB instance.
      • D. Copy the snapshots to an Amazon S3 bucket that is encrypted using server-side encryption with AWS Key Management Service (AWS KMS) managed keys (SSE-KMS).

      Domain: Design Secure Architectures

      Correct answer: A

      • A. Correct — RDS doesn't support turning on encryption for an existing unencrypted instance in place; the supported path is to encrypt a copy of a snapshot, then restore a new (replacement) DB instance from that encrypted snapshot.
      • B. Wrong — a managed RDS instance's underlying storage isn't something you swap for a separately created EBS volume, and there's no option to simply "enable encryption" on an existing unencrypted RDS instance.
      • C. Wrong — encrypting a copied snapshot with KMS is correct, but restoring an encrypted snapshot always creates a brand-new DB instance — it can never be restored "to an existing DB instance."
      • D. Wrong — RDS snapshots are managed within the RDS/backup snapshot system; they aren't copied into an S3 bucket as a way to encrypt or use them.

      Question 29

      A company sells ringtones created from clips of popular songs. The files containing the ringtones are stored in Amazon S3 Standard and are at least 128 KB in size. The company has millions of files, but downloads are infrequent for ringtones older than 90 days. The company needs to save money on storage while keeping the most accessed files readily available for its users. Which action should the company take to meet these requirements MOST cost-effectively?

      • A. Configure S3 Standard-Infrequent Access (S3 Standard-IA) storage for the initial storage tier of the objects.
      • B. Move the files to S3 Intelligent-Tiering and configure it to move objects to a less expensive storage tier after 90 days.
      • C. Configure S3 inventory to manage objects and move them to S3 Standard-Infrequent Access (S3 Standard-IA) after 90 days.
      • D. Implement an S3 Lifecycle policy that moves the objects from S3 Standard to S3 Standard-Infrequent Access (S3 Standard-IA) after 90 days.

      Domain: Design Cost-Optimized Architectures

      Correct answer: D

      • A. Wrong — putting every file in Standard-IA immediately means the frequently-downloaded files (under 90 days old) incur Standard-IA's per-GB retrieval fees unnecessarily, which isn't optimal for actively accessed content.
      • B. Wrong — Intelligent-Tiering adds a small per-object monitoring fee and is designed for unpredictable access patterns; here the access pattern (frequent, then rare after exactly 90 days) is already known, so a plain Lifecycle rule is simpler and cheaper.
      • C. Wrong — S3 Inventory is a reporting tool that lists objects and their metadata; it doesn't transition objects between storage classes itself.
      • D. Correct — a Lifecycle policy transitioning from S3 Standard to S3 Standard-IA at exactly the known 90-day access-pattern change point keeps recent, frequently-accessed files fast and fully available, then cuts storage cost for older files, with no extra monitoring fees.

      Question 30

      A company has a highly dynamic batch processing job that uses many Amazon EC2 instances to complete it. The job is stateless in nature, can be started and stopped at any given time with no negative impact, and typically takes upwards of 60 minutes total to complete. The company has asked a solutions architect to design a scalable and cost-effective solution that meets the requirements of the job. What should the solutions architect recommend?

      • A. Implement EC2 Spot Instances.
      • B. Purchase EC2 Reserved Instances.
      • C. Implement EC2 On-Demand Instances.
      • D. Implement the processing on AWS Lambda.

      Domain: Design Cost-Optimized Architectures

      Correct answer: A

      • A. Correct — a stateless job that can start/stop anytime with no negative impact is exactly the profile Spot Instances are built for, offering the deepest EC2 discount for interruption-tolerant workloads.
      • B. Wrong — Reserved Instances commit to steady, predictable long-term usage; a "highly dynamic" job with variable instance needs doesn't fit a 1- or 3-year RI commitment.
      • C. Wrong — On-Demand costs more than Spot for a workload explicitly described as tolerant of interruption, leaving savings on the table.
      • D. Wrong — Lambda has a maximum execution timeout of 15 minutes, well short of a job that "typically takes upwards of 60 minutes," so it can't run as a single Lambda invocation as described.

      Question 31

      An application runs on Amazon EC2 instances across multiple Availability Zones. The instances run in an Amazon EC2 Auto Scaling group behind an Application Load Balancer. The application performs best when the CPU utilization of the EC2 instances is at or near 40%. What should a solutions architect do to maintain the desired performance across all instances in the group?

      • A. Use a simple scaling policy to dynamically scale the Auto Scaling group.
      • B. Use a target tracking policy to dynamically scale the Auto Scaling group.
      • C. Use an AWS Lambda function to update the desired Auto Scaling group capacity.
      • D. Use scheduled scaling actions to scale up and scale down the Auto Scaling group.

      Domain: Design High-Performing Architectures

      Correct answer: B

      • A. Wrong — simple scaling reacts to one alarm breach at a time with a cooldown between actions, making it slower and less precise at continuously holding a metric at a specific value than target tracking.
      • B. Correct — a target tracking policy is purpose-built to continuously adjust capacity to keep a chosen metric, like average CPU utilization, at a specified target value — exactly "maintain ~40% CPU across all instances."
      • C. Wrong — a custom Lambda function to manually adjust desired capacity reinvents what a built-in target tracking policy already solves natively.
      • D. Wrong — scheduled scaling changes capacity at fixed times; it doesn't dynamically respond to the actual, real-time CPU utilization metric.

      Question 32

      A global company hosts its web application on Amazon EC2 instances behind an Application Load Balancer (ALB). The web application has static data and dynamic data. The company stores its static data in an Amazon S3 bucket. The company wants to improve performance and reduce latency for the static data and dynamic data. The company is using its own domain name registered with Amazon Route 53. What should a solutions architect do to meet these requirements?

      • A. Create an Amazon CloudFront distribution that has the S3 bucket and the ALB as origins. Configure Route 53 to route traffic to the CloudFront distribution.
      • B. Create an Amazon CloudFront distribution that has the ALB as an origin. Create an AWS Global Accelerator standard accelerator that has the S3 bucket as an endpoint. Configure Route 53 to route traffic to the CloudFront distribution.
      • C. Create an Amazon CloudFront distribution that has the S3 bucket as an origin. Create an AWS Global Accelerator standard accelerator that has the ALB and the CloudFront distribution as endpoints. Create a custom domain name that points to the accelerator DNS name. Use the custom domain name as an endpoint for the web application.
      • D. Create an Amazon CloudFront distribution that has the ALB as an origin. Create an AWS Global Accelerator standard accelerator that has the S3 bucket as an endpoint. Create two domain names. Point one domain name to the CloudFront DNS name for dynamic content. Point the other domain name to the accelerator DNS name for static content. Use the domain names as endpoints for the web application.

      Domain: Design High-Performing Architectures

      Correct answer: A

      • A. Correct — one CloudFront distribution can have both the S3 bucket and the ALB as origins, using cache behaviors to route static vs. dynamic paths appropriately, and Route 53 simply points the single domain at that one distribution — the standard, simplest way to accelerate mixed static/dynamic content globally.
      • B. Wrong — adding a separate Global Accelerator endpoint just for the S3 bucket is unnecessary complexity; cacheable static S3 content is already well served by CloudFront's edge caching.
      • C. Wrong — layering Global Accelerator over both the ALB and the CloudFront distribution behind one custom domain is a convoluted, non-standard combination that adds cost and complexity beyond what two data types require.
      • D. Wrong — splitting traffic across two separate domain names (one via CloudFront, one via Global Accelerator) is more complex for both the client and the app to manage than a single CloudFront distribution with two origins under one domain.

      Question 33

      A company's containerized application runs on an Amazon EC2 instance. The application needs to download security certificates before it can communicate with other business applications. The company wants a highly secure solution to encrypt and decrypt the certificates in near real time. The solution also needs to store data in highly available storage after the data is encrypted. Which solution will meet these requirements with the LEAST operational overhead?

      • A. Create AWS Secrets Manager secrets for encrypted certificates. Manually update the certificates as needed. Control access to the data by using fine-grained IAM access.
      • B. Create an AWS Lambda function that uses the Python cryptography library to receive and perform encryption operations. Store the function in an Amazon S3 bucket.
      • C. Create an AWS Key Management Service (AWS KMS) customer managed key. Allow the EC2 role to use the KMS key for encryption operations. Store the encrypted data on Amazon S3.
      • D. Create an AWS Key Management Service (AWS KMS) customer managed key. Allow the EC2 role to use the KMS key for encryption operations. Store the encrypted data on Amazon Elastic Block Store (Amazon EBS) volumes.

      Domain: Design Secure Architectures

      Correct answer: C

      • A. Wrong — Secrets Manager is for storing/rotating credentials, not a general-purpose near-real-time encrypt/decrypt service for certificate data, and "manually update... as needed" adds operational overhead.
      • B. Wrong — building a custom Lambda function with a third-party crypto library is far more operational overhead (code to write, maintain, and secure) than using a managed encryption service.
      • C. Correct — AWS KMS is purpose-built for this: a customer managed key lets the EC2 instance role perform fast encrypt/decrypt operations, and storing the encrypted result on S3 (which is highly available by design) satisfies every requirement with only managed services.
      • D. Wrong — EBS volumes are tied to a single Availability Zone and aren't inherently highly available the way S3 is, making S3 the better fit for the stated highly-available-storage requirement.

      Question 34

      A company recently migrated a message processing system to AWS. The system receives messages into an ActiveMQ queue running on an Amazon EC2 instance. Messages are processed by a consumer application running on Amazon EC2. The consumer application processes the messages and writes results to a MySQL database running on Amazon EC2. The company wants this application to be highly available with low operational complexity. Which architecture offers the HIGHEST availability?

      • A. Add a second ActiveMQ server to another Availability Zone. Add an additional consumer EC2 instance in another Availability Zone. Replicate the MySQL database to another Availability Zone.
      • B. Use Amazon MQ with active/standby brokers configured across two Availability Zones. Add an additional consumer EC2 instance in another Availability Zone. Replicate the MySQL database to another Availability Zone.
      • C. Use Amazon MQ with active/standby brokers configured across two Availability Zones. Add an additional consumer EC2 instance in another Availability Zone. Use Amazon RDS for MySQL with Multi-AZ enabled.
      • D. Use Amazon MQ with active/standby brokers configured across two Availability Zones. Add an Auto Scaling group for the consumer EC2 instances across two Availability Zones. Use Amazon RDS for MySQL with Multi-AZ enabled.

      Domain: Design Resilient Architectures

      Correct answer: D

      • A. Wrong — adding a second self-managed ActiveMQ server, an extra consumer instance, and manually "replicating" MySQL yourself all require building and operating failover logic by hand, with no managed HA guarantees.
      • B. Wrong — moving the broker to managed Amazon MQ active/standby helps, but manually replicating MySQL yourself still leaves the database tier as a self-managed, custom-failover component rather than a managed HA solution.
      • C. Wrong — this is close, but the consumer tier is still just "an additional" fixed EC2 instance rather than an Auto Scaling group, so the compute tier has no automatic replacement if an instance fails.
      • D. Correct — every tier gets a managed, auto-failover HA option: Amazon MQ active/standby for the broker, an Auto Scaling group across AZs for the consumer compute tier, and Multi-AZ RDS for MySQL for the database — the highest availability with the least custom operational work.

      Question 35

      A company hosts a website analytics application on a single Amazon EC2 On-Demand Instance. The analytics software is written in PHP and uses a MySQL database. The analytics software, the web server that provides PHP, and the database server are all hosted on the EC2 instance. The application is showing signs of performance degradation during busy times and is presenting 5xx errors. The company needs to make the application scale seamlessly. Which solution will meet these requirements MOST cost-effectively?

      • A. Migrate the database to an Amazon RDS for MySQL DB instance. Create an AMI of the web application. Use the AMI to launch a second EC2 On-Demand Instance. Use an Application Load Balancer to distribute the load to each EC2 instance.
      • B. Migrate the database to an Amazon RDS for MySQL DB instance. Create an AMI of the web application. Use the AMI to launch a second EC2 On-Demand Instance. Use Amazon Route 53 weighted routing to distribute the load across the two EC2 instances.
      • C. Migrate the database to an Amazon Aurora MySQL DB instance. Create an AWS Lambda function to stop the EC2 instance and change the instance type. Create an Amazon CloudWatch alarm to invoke the Lambda function when CPU utilization surpasses 75%.
      • D. Migrate the database to an Amazon Aurora MySQL DB instance. Create an AMI of the web application. Apply the AMI to a launch template. Create an Auto Scaling group with the launch template. Configure the launch template to use a Spot Fleet. Attach an Application Load Balancer to the Auto Scaling group.

      Domain: Design Cost-Optimized Architectures

      Correct answer: D

      • A. Wrong — manually launching a fixed second On-Demand instance behind an ALB caps capacity at exactly two instances; it doesn't scale seamlessly as demand actually changes.
      • B. Wrong — Route 53 weighted routing splits traffic by a fixed percentage across two static instances; it doesn't add or remove capacity dynamically, so it isn't seamless scaling either.
      • C. Wrong — stopping the instance and changing its instance type via Lambda causes an outage during every resize and doesn't provide true horizontal, seamless scaling for a live web application under load.
      • D. Correct — moving the database onto managed Aurora removes the single-instance database bottleneck, and a launch-template-based Auto Scaling group (using a Spot Fleet for lower cost) behind an ALB gives seamless, elastic, and cost-effective horizontal scaling of the web tier.

      Question 36

      A company wants to build a scalable key management infrastructure to support developers who need to encrypt data in their applications. What should a solutions architect do to reduce the operational burden?

      • A. Use multi-factor authentication (MFA) to protect the encryption keys.
      • B. Use AWS Key Management Service (AWS KMS) to protect the encryption keys.
      • C. Use AWS Certificate Manager (ACM) to create, store, and assign the encryption keys.
      • D. Use an IAM policy to limit the scope of users who have access permissions to protect the encryption keys.

      Domain: Design Secure Architectures

      Correct answer: B

      • A. Wrong — MFA protects user sign-in; it isn't a key management mechanism and doesn't provide encryption keys to applications.
      • B. Correct — AWS KMS is the managed key management service purpose-built to create, store, and let applications use encryption keys at scale, with virtually no infrastructure to operate — directly minimizing operational burden.
      • C. Wrong — ACM issues and manages TLS/SSL certificates for encryption in transit; it doesn't create or manage general-purpose data encryption keys for applications.
      • D. Wrong — an IAM policy only controls who can access keys; it doesn't create, store, or manage the encryption keys themselves.

      Question 37

      A company hosts a data lake on AWS. The data lake consists of data in Amazon S3 and Amazon RDS for PostgreSQL. The company needs a reporting solution that provides data visualization and includes all the data sources within the data lake. Only the company's management team should have full access to all the visualizations. The rest of the company should have only limited access. Which solution will meet these requirements?

      • A. Create an analysis in Amazon QuickSight. Connect all the data sources and create new datasets. Publish dashboards to visualize the data. Share the dashboards with the appropriate IAM roles.
      • B. Create an analysis in Amazon QuickSight. Connect all the data sources and create new datasets. Publish dashboards to visualize the data. Share the dashboards with the appropriate users and groups.
      • C. Create an AWS Glue table and crawler for the data in Amazon S3. Create an AWS Glue extract, transform, and load (ETL) job to produce reports. Publish the reports to Amazon S3. Use S3 bucket policies to limit access to the reports.
      • D. Create an AWS Glue table and crawler for the data in Amazon S3. Use Amazon Athena Federated Query to access data within Amazon RDS for PostgreSQL. Generate reports by using Amazon Athena. Publish the reports to Amazon S3. Use S3 bucket policies to limit access to the reports.

      Domain: Design Secure Architectures

      Correct answer: B

      • A. Wrong — sharing dashboards with "IAM roles" isn't how QuickSight sharing works; QuickSight manages its own users and groups rather than granting dashboard access directly to IAM roles.
      • B. Correct — QuickSight can connect to both S3 and RDS for PostgreSQL in one analysis, and its own user/group sharing model lets the management team get full dashboard access while everyone else gets limited access.
      • C. Wrong — a Glue ETL pipeline producing static reports in S3 isn't an interactive data-visualization/BI tool, and it only covers the S3 data, not the required RDS for PostgreSQL source.
      • D. Wrong — Athena Federated Query can reach into RDS for PostgreSQL, but Athena doesn't provide interactive dashboards/visualizations, and S3 bucket policies grant broad object-level access rather than the fine-grained "management full access vs. everyone else limited" visualization-level control required.

      Question 38

      A company runs its media rendering application on premises. The company wants to reduce storage costs and has moved all data to Amazon S3. The on-premises rendering application needs low-latency access to storage. The company needs to design a storage solution for the application. The storage solution must maintain the desired application performance. Which storage solution will meet these requirements in the MOST cost-effective way?

      • A. Use Mountpoint for Amazon S3 to access the data in Amazon S3 for the on-premises application.
      • B. Configure an Amazon S3 File Gateway to provide storage for the on-premises application.
      • C. Copy the data from Amazon S3 to Amazon FSx for Windows File Server. Configure an Amazon FSx File Gateway to provide storage for the on-premises application.
      • D. Configure an on-premises file server. Use the Amazon S3 API to connect to S3 storage. Configure the application to access the storage from the on-premises file server.

      Domain: Design Cost-Optimized Architectures

      Correct answer: B

      • A. Wrong — Mountpoint for Amazon S3 mounts S3 as a file system from AWS compute (like EC2); it isn't designed for an on-premises server reaching S3 across the internet with guaranteed low latency.
      • B. Correct — an S3 File Gateway provides a local on-premises NFS/SMB endpoint backed by S3, with a local cache keeping frequently accessed data available at low latency on-premises, while bulk storage cost lives cheaply in S3.
      • C. Wrong — copying data into FSx for Windows File Server (behind an FSx File Gateway) means paying for FSx storage on top of the S3 copy, a more expensive, redundant footprint than simply gatewaying S3 directly.
      • D. Wrong — building and maintaining a custom on-premises file server that calls the S3 API directly, instead of using AWS's managed gateway, has no local caching for latency and more ongoing operational effort.

      Question 39

      A digital image processing company wants to migrate its on-premises monolithic application to the AWS Cloud. The company processes thousands of images and generates large files as part of the processing workflow. The company needs a solution to manage the growing number of image processing jobs. The solution must also reduce the manual tasks in the image processing workflow. The company does not want to manage the underlying infrastructure of the solution. Which solution will meet these requirements with the LEAST operational overhead?

      • A. Use Amazon Elastic Container Service (Amazon ECS) with Amazon EC2 Spot Instances to process the images. Configure Amazon Simple Queue Service (Amazon SQS) to orchestrate the workflow. Store the processed files in Amazon Elastic File System (Amazon EFS).
      • B. Use AWS Batch jobs to process the images. Use AWS Step Functions to orchestrate the workflow. Store the processed files in an Amazon S3 bucket.
      • C. Use AWS Lambda functions and Amazon EC2 Spot Instances to process the images. Store the processed files in Amazon FSx.
      • D. Deploy a group of Amazon EC2 instances to process the images. Use AWS Step Functions to orchestrate the workflow. Store the processed files in an Amazon Elastic Block Store (Amazon EBS) volume.

      Domain: Design High-Performing Architectures

      Correct answer: B

      • A. Wrong — ECS with the EC2 Spot launch type still requires managing and scaling the underlying EC2 cluster capacity, which is infrastructure the company said it doesn't want to manage.
      • B. Correct — AWS Batch fully manages provisioning and scaling of compute with nothing to manage directly, Step Functions orchestrates the multi-step workflow to cut manual tasks, and S3 is the natural durable store for the large generated files.
      • C. Wrong — EC2 Spot Instances still need managing/orchestrating alongside the Lambda triggers, and Amazon FSx requires provisioning and managing a file system — both conflict with "does not want to manage the underlying infrastructure."
      • D. Wrong — deploying and managing a group of EC2 instances directly is exactly the infrastructure management the company wants to avoid, and an EBS volume is tied to a single instance/AZ, unsuitable as a shared output store.

      Question 40

      A company recently migrated to AWS and wants to implement a solution to protect the traffic that flows in and out of the production VPC. The company had an inspection server in its on-premises data center. The inspection server performed specific operations such as traffic flow inspection and traffic filtering. The company wants to have the same functionalities in the AWS Cloud. Which solution will meet these requirements?

      • A. Use Amazon GuardDuty for traffic inspection and traffic filtering in the production VPC.
      • B. Use Traffic Mirroring to mirror traffic from the production VPC for traffic inspection and filtering.
      • C. Use AWS Network Firewall to create the required rules for traffic inspection and traffic filtering for the production VPC.
      • D. Use AWS Firewall Manager to create the required rules for traffic inspection and traffic filtering for the production VPC.

      Domain: Design Secure Architectures

      Correct answer: C

      • A. Wrong — GuardDuty is a threat-detection service that analyzes logs and produces findings; it does not inline-inspect or filter live traffic flowing in and out of a VPC.
      • B. Wrong — Traffic Mirroring copies traffic for out-of-band analysis; it doesn't itself filter or block traffic, so it can't replace an inline inspection/filtering appliance.
      • C. Correct — AWS Network Firewall is a managed, stateful firewall service that inspects and filters traffic flowing in and out of a VPC, directly replacing the on-premises inspection server's functions.
      • D. Wrong — AWS Firewall Manager centrally deploys and manages firewall policies (like Network Firewall or WAF rules) across accounts; it isn't itself the traffic inspection/filtering engine — Network Firewall is.

      Question 41

      A company is building a containerized application on premises and decides to move the application to AWS. The application will have thousands of users soon after it is deployed. The company is unsure how to manage the deployment of containers at scale. The company needs to deploy the containerized application in a highly available architecture that minimizes operational overhead. Which solution will meet these requirements?

      • A. Store container images in an Amazon Elastic Container Registry (Amazon ECR) repository. Use an Amazon Elastic Container Service (Amazon ECS) cluster with the AWS Fargate launch type to run the containers. Use target tracking to scale automatically based on demand.
      • B. Store container images in an Amazon Elastic Container Registry (Amazon ECR) repository. Use an Amazon Elastic Container Service (Amazon ECS) cluster with the Amazon EC2 launch type to run the containers. Use target tracking to scale automatically based on demand.
      • C. Store container images in a repository that runs on an Amazon EC2 instance. Run the containers on EC2 instances that are spread across multiple Availability Zones. Monitor the average CPU utilization in Amazon CloudWatch. Launch new EC2 instances as needed.
      • D. Create an Amazon EC2 Amazon Machine Image (AMI) that contains the container image. Launch EC2 instances in an Auto Scaling group across multiple Availability Zones. Use an Amazon CloudWatch alarm to scale out EC2 instances when the average CPU utilization threshold is breached.

      Domain: Design High-Performing Architectures

      Correct answer: A

      • A. Correct — ECR stores the images, an ECS cluster on Fargate removes all server/cluster management (nothing to patch or scale directly), and target tracking auto-scales the service with demand — the least operational overhead, most managed option.
      • B. Wrong — the EC2 launch type for ECS still requires provisioning, patching, and scaling the underlying EC2 instances in the cluster, exactly the container-deployment-at-scale burden the company is unsure how to handle.
      • C. Wrong — a self-managed image repository on EC2 plus manually launching instances based on CloudWatch CPU monitoring is a fully manual, high-overhead approach with no built-in container orchestration.
      • D. Wrong — baking an AMI with the container image and scaling plain EC2 instances abandons container orchestration entirely and still requires managing EC2 instances, patching, and capacity directly.

      Question 42

      A company has a three-tier web application that processes orders from customers. The web tier consists of Amazon EC2 instances behind an Application Load Balancer. The processing tier consists of EC2 instances. The company decoupled the web tier and processing tier by using Amazon Simple Queue Service (Amazon SQS). The storage layer uses Amazon DynamoDB. At peak times, some users report order processing delays and stalls. The company has noticed that during these delays, the EC2 instances are running at 100% CPU usage, and the SQS queue fills up. The peak times are variable and unpredictable. The company needs to improve the performance of the application. Which solution will meet these requirements?

      • A. Use scheduled scaling for Amazon EC2 Auto Scaling to scale out the processing tier instances for the duration of peak usage times. Use the CPU Utilization metric to determine when to scale.
      • B. Use Amazon ElastiCache for Redis in front of the DynamoDB backend tier. Use target utilization as a metric to determine when to scale.
      • C. Add an Amazon CloudFront distribution to cache the responses for the web tier. Use HTTP latency as a metric to determine when to scale.
      • D. Use an Amazon EC2 Auto Scaling target tracking policy to scale out the processing tier instances. Use the ApproximateNumberOfMessages attribute to determine when to scale.

      Domain: Design High-Performing Architectures

      Correct answer: D

      • A. Wrong — scheduled scaling only works for known, predictable time windows; the peak times here are explicitly "variable and unpredictable," so a fixed schedule can't anticipate them.
      • B. Wrong — a cache in front of DynamoDB might help read performance on the storage layer, but the described bottleneck is the processing tier's EC2 CPU maxing out and the queue backing up, not the storage layer.
      • C. Wrong — CloudFront caching helps with cacheable web-tier content, but the reported issue is 100% CPU on the processing tier and a growing SQS backlog, not web-tier response caching.

      Question 43

      A company wants to migrate its on-premises data center to AWS. According to the company's compliance requirements, the company can use only the ap-northeast-3 Region. Company administrators are not permitted to connect VPCs to the internet. Which solutions will meet these requirements? (Choose two.)

      • A. Use AWS Control Tower to implement data residency guardrails to deny internet access and deny access to all AWS Regions except ap-northeast-3.
      • B. Use rules in AWS WAF to prevent internet access. Deny access to all AWS Regions except ap-northeast-3 in the AWS account settings.
      • C. Use AWS Organizations to configure service control policies (SCPs) that prevent VPCs from gaining internet access. Deny access to all AWS Regions except ap-northeast-3.

      • E. Use AWS Config to activate managed rules to detect and alert for internet gateways and to detect and alert for new resources deployed outside of ap-northeast-3.

      Domain: Design Secure Architectures

      Correct answer: A, C

      • A. Correct — Control Tower's data residency guardrails (built on SCPs under the hood) can be configured to deny internet gateway creation and deny API access to every Region except the approved one, centrally enforcing both requirements.

Wrong — a per-VPC network ACL rule is easy to omit on a newly created VPC and doesn't stop someone from creating an internet gateway in the first place, and per-user IAM Region-restriction policies must be applied consistently to every IAM principal — far less centralized and reliable than an org-wide SCP.

      A gaming company is designing a highly available architecture. The application runs on a modified Linux kernel and supports only UDP-based traffic.       Correct answer: A, E
