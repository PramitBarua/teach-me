# Mission: AWS Solutions Architect Associate (SAA-C03)

## Why
Pass the AWS Solutions Architect Associate (SAA-C03) certification exam to validate cloud architecture skills and advance as a cloud practitioner. The certification is a widely recognised credential that opens doors to cloud architect roles and projects.

## Success looks like
- Pass the AWS SAA-C03 exam with a score of 720 or above
- Understand core AWS services well enough to answer scenario-based exam questions confidently
- Be able to explain IAM, networking, compute, virtual private cloud, serverless, storage, and database trade-offs in AWS

## Constraints
- Learning is self-paced via Adrian Cantrill's course notes
- Lessons should be isolated per topic so the learner can revisit individual areas without re-reading the whole course
- Lessons must support retrieval practice to build long-term retention, not just fluency

## Out of scope
- Deep production implementation (hands-on labs are supplementary, not primary)
- Topics not in the SAA-C03 exam guide
